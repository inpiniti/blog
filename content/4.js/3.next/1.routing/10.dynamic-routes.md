---
title: 동적 라우팅(Dynamic Routes)
---

동적 라우팅이란 **URL의 일부를 변수로 처리**하여 다양한 경로를 하나의 페이지에서 처리할 수 있는 기능입니다. 예를 들어, `/products/1`, `/products/2`와 같은 경로를 하나의 컴포넌트로 처리할 수 있습니다. 이 기능은 Next.js에서 **파일 시스템 라우팅과 결합**되어 간단하게 구현됩니다.

---

### 1. **동적 경로 파일 설정하기**  
Next.js에서는 동적 경로를 **대괄호 `[ ]`**로 감싸서 파일 이름으로 사용합니다.

#### 예제: 파일 구조
```
/app
  /products
    /[id]
      page.js  # 각 제품 ID에 따라 다른 페이지를 렌더링
```

이 예제에서는 **`[id]`**가 동적 경로입니다. `/products/1`이나 `/products/42` 같은 경로로 접근하면 해당 ID에 맞는 내용을 렌더링합니다.

---

### 2. **동적 경로에서 데이터 사용하기**  
동적 경로를 사용하면, Next.js는 **경로의 파라미터**를 자동으로 인식해 사용할 수 있습니다.

#### 예제: `page.js`에서 파라미터 사용
```javascript
export default function ProductPage({ params }) {
  const { id } = params; // URL에서 id 추출

  return (
    <div>
      <h1>제품 ID: {id}</h1>
      <p>이 제품에 대한 정보를 여기에 표시합니다.</p>
    </div>
  );
}
```

이 코드는 `/products/1`로 접근하면 `id` 값이 `1`로, `/products/42`로 접근하면 `id` 값이 `42`로 사용됩니다.

---

### 3. **여러 파라미터 사용하기**  
하나 이상의 파라미터를 동적으로 사용할 수 있습니다.

#### 예제: 파일 구조
```
/app
  /category
    /[category]
      /[productId]
        page.js
```

**`page.js`** 코드:
```javascript
export default function ProductCategoryPage({ params }) {
  const { category, productId } = params;

  return (
    <div>
      <h1>{category} 카테고리의 제품 ID: {productId}</h1>
    </div>
  );
}
```

- `/category/electronics/1` 같은 경로로 접근하면 `category`는 `electronics`, `productId`는 `1`로 전달됩니다.

---

### 4. **옵셔널 동적 경로**  
동적 경로가 **옵션**인 경우도 처리할 수 있습니다. 이때 **대괄호 안에 물음표 `[ ]?`**를 사용합니다.

#### 예제:
```
/app
  /blog
    /[slug]?
      page.js
```

**`page.js`** 코드:
```javascript
export default function BlogPage({ params }) {
  const { slug } = params || {};

  if (!slug) {
    return <h1>모든 블로그 포스트 보기</h1>;
  }

  return <h1>블로그 포스트: {slug}</h1>;
}
```

- `/blog`로 접근하면 "모든 블로그 포스트 보기"가 렌더링되고, `/blog/my-first-post`로 접근하면 "블로그 포스트: my-first-post"가 표시됩니다.

---

### 5. **404 페이지 처리하기**  
존재하지 않는 동적 경로에 대한 **404 페이지**를 자동으로 처리하거나, 원하는 방식으로 제어할 수 있습니다.

#### 예제:
```javascript
export default function ProductPage({ params }) {
  const { id } = params;

  if (isNaN(id)) {
    return <h1>404: 존재하지 않는 제품입니다.</h1>;
  }

  return <h1>제품 ID: {id}</h1>;
}
```

- `/products/abc`처럼 잘못된 경로로 접근하면 "404: 존재하지 않는 제품입니다" 메시지를 표시합니다.

---

### 6. **클라이언트 네비게이션과 동적 라우팅**  
Next.js의 **`useRouter`** 훅을 사용하면 클라이언트 측에서도 동적 라우팅을 제어할 수 있습니다.

#### 예제: `useRouter` 사용하기
```javascript
'use client';

import { useRouter } from 'next/navigation';

export default function NavigateButton() {
  const router = useRouter();

  return (
    <button onClick={() => router.push('/products/5')}>
      제품 5로 이동
    </button>
  );
}
```

- 버튼을 클릭하면 **`/products/5`** 경로로 이동합니다.

---

### 7. **동적 경로의 SEO와 최적화**  
동적 라우트가 많은 경우 **SEO 최적화**를 위해 서버 사이드 렌더링(SSR)이나 정적 생성(SSG)을 사용합니다.

- **SSR**: 페이지 요청 시마다 서버에서 데이터를 렌더링  
- **SSG**: 빌드 시 모든 경로의 HTML 파일을 미리 생성  

---

### 요약  
- **동적 라우팅**은 Next.js에서 **대괄호 `[ ]`**를 사용해 파일 경로에 정의합니다.  
- 여러 파라미터나 **옵셔널 경로**도 처리할 수 있어 유연한 라우팅이 가능합니다.  
- **`useRouter`**를 사용해 클라이언트 측 네비게이션을 제어할 수 있습니다.  
- 동적 라우트를 활용할 때는 **SEO 최적화**와 404 페이지 처리도 고려하는 것이 좋습니다.

동적 라우팅을 활용하면 **유연한 URL 구조**와 **확장성 높은 애플리케이션**을 쉽게 개발할 수 있습니다! 🚀
