---
title: 병렬 라우트(Parallel Routes)
---

**병렬 라우트(Parallel Routes)**란 여러 경로를 동시에 렌더링할 수 있게 하는 기능입니다. 이 기능은 다양한 화면이나 콘텐츠를 동시에 보여주고자 할 때 매우 유용합니다. 특히, 대시보드와 같은 복잡한 레이아웃을 구성할 때 **서브 섹션**을 동시에 렌더링할 수 있습니다.

---

### 1. **병렬 라우트의 기본 개념**

기존의 중첩 라우트(Nested Routes)와 달리 병렬 라우트는 **동시에 여러 경로를 독립적으로 렌더링**합니다.  
예를 들어, 대시보드에서 **왼쪽 사이드바, 메인 콘텐츠, 알림 창**을 각각 병렬로 렌더링할 수 있습니다.

#### 예제: 병렬 라우트 구조
```
/app
  /@sidebar
    layout.js  # 사이드바 레이아웃
  /@main
    page.js    # 메인 콘텐츠
  /@notifications
    page.js    # 알림 페이지
```

- **`@sidebar`**, **`@main`**, **`@notifications`**는 각각 독립적인 병렬 라우트입니다.
- 이들은 같은 화면에서 **동시에 렌더링**되며, 서로의 상태에 영향을 주지 않습니다.

---

### 2. **레이아웃에서 병렬 라우트 설정하기**

병렬 라우트는 **`layout.js`** 파일에서 정의됩니다.

#### 예제: `layout.js`에서 병렬 라우트 설정
```javascript
export default function RootLayout({ sidebar, main, notifications }) {
  return (
    <div style={{ display: 'flex' }}>
      <aside>{sidebar}</aside>
      <main>{main}</main>
      <div className="notifications">{notifications}</div>
    </div>
  );
}
```

- **`RootLayout`**은 `sidebar`, `main`, `notifications`라는 세 가지 병렬 라우트를 동시에 렌더링합니다.

---

### 3. **라우트에 컴포넌트 매핑하기**

각 병렬 라우트에 맞는 컴포넌트를 배치합니다.

#### 예제: `/@sidebar/layout.js`
```javascript
export default function SidebarLayout() {
  return <nav>사이드바 메뉴</nav>;
}
```

#### 예제: `/@main/page.js`
```javascript
export default function MainPage() {
  return <h1>메인 콘텐츠</h1>;
}
```

#### 예제: `/@notifications/page.js`
```javascript
export default function NotificationsPage() {
  return <p>알림이 없습니다.</p>;
}
```

이렇게 하면 **사이드바**, **메인 콘텐츠**, **알림 창**이 한 화면에 병렬로 렌더링됩니다.

---

### 4. **병렬 라우트의 사용 예시**

#### **대시보드 예시**
대시보드에서는 **사이드바, 메인 콘텐츠, 알림 창**이 독립적으로 작동해야 합니다.  
사용자가 알림 창을 닫아도 메인 콘텐츠와 사이드바는 그대로 유지됩니다.

#### **모바일 앱처럼 구성하기**
병렬 라우트를 사용하면, 모바일 앱처럼 **탭을 전환해도 다른 섹션의 상태가 유지**됩니다.

---

### 5. **동적 병렬 라우트 사용하기**

병렬 라우트는 **동적 경로**와도 결합할 수 있습니다.

#### 예제:
```
/app
  /@main
    /[id]
      page.js  # 동적으로 ID에 따라 콘텐츠 렌더링
```

**`page.js`**:
```javascript
export default function ProductPage({ params }) {
  const { id } = params;
  return <h1>제품 ID: {id}</h1>;
}
```

- `/main/1`로 접근하면 **제품 ID 1**이 표시됩니다.
- `/main/2`로 접근하면 **제품 ID 2**가 표시됩니다.

---

### 6. **에러 처리와 병렬 라우트**

병렬 라우트에서도 **에러 처리가 독립적**으로 가능합니다.  
각 병렬 라우트에 **에러 경계(Error Boundary)**를 설정하여 특정 경로에 문제가 생겨도 나머지 섹션이 정상적으로 렌더링됩니다.

#### 예제: `layout.js`에서 에러 처리
```javascript
export default function RootLayout({ sidebar, main, notifications }) {
  return (
    <div style={{ display: 'flex' }}>
      <aside>{sidebar || <p>사이드바를 불러올 수 없습니다.</p>}</aside>
      <main>{main}</main>
      <div className="notifications">
        {notifications || <p>알림을 불러올 수 없습니다.</p>}
      </div>
    </div>
  );
}
```

### 7. **클라이언트 네비게이션과 병렬 라우트**

병렬 라우트를 사용할 때 **`useRouter`** 훅을 사용해 특정 섹션만 네비게이션할 수 있습니다.

#### 예제:
```javascript
'use client';

import { useRouter } from 'next/navigation';

export default function NavigateButton() {
  const router = useRouter();

  return (
    <button onClick={() => router.push('/@notifications')}>
      알림 보기
    </button>
  );
}
```

- 버튼을 누르면 알림 페이지가 병렬로 렌더링됩니다.

---

### 8. **SEO와 병렬 라우트 최적화**

병렬 라우트는 **서버 측 렌더링(SSR)**과 **정적 사이트 생성(SSG)**에도 잘 작동합니다.  
SEO 최적화를 위해 중요한 콘텐츠는 **서버에서 미리 렌더링**하는 것이 좋습니다.

---

### 요약

- **병렬 라우트(Parallel Routes)**를 사용하면 여러 섹션을 동시에 렌더링할 수 있습니다.  
- 대시보드와 같이 복잡한 화면을 쉽게 구성할 수 있습니다.  
- **동적 경로**와 **에러 처리**를 병렬 라우트에 적용해 유연한 라우팅을 구현할 수 있습니다.  
- **`useRouter`** 훅을 사용해 클라이언트 측 네비게이션도 지원합니다.

병렬 라우트를 활용하면 복잡한 UI를 효율적으로 관리할 수 있습니다. 여러 섹션이 **독립적으로 렌더링되고 유지**되므로 사용자의 경험이 더욱 향상됩니다! 🚀
