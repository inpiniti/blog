---
title: 경로 가로채기(Intercepting Routes)
---

경로 가로채기란 **사용자가 특정 경로로 이동할 때 중간에 다른 UI를 보여주거나, 흐름을 잠시 변경하는 기능**입니다. 주로 **모달 창**, **인앱 알림**, 또는 **임시 경로 처리**가 필요할 때 사용됩니다.

---

### 1. **기본 개념: 경로 가로채기의 목적**

가로채기는 사용자가 이동 중인 경로를 변경하지 않고, **원래 화면 위에 임시로 다른 컴포넌트**를 보여줄 수 있게 합니다. 예를 들어, 상세 페이지로 이동하기 전 **모달 창**을 띄우거나 **폼 입력 중 확인 팝업**을 보여줄 때 유용합니다.

---

### 2. **경로 가로채기 구조**  

Next.js에서는 **`( ...)`**로 경로를 감싸는 방식을 통해 가로채기를 설정합니다.

#### 예제: 파일 구조
```
/app
  /products
    page.js
    /(modals)
      /review
        page.js
```

- **`(modals)`**는 경로를 가로채는 역할을 합니다.
- 사용자가 `/products`로 이동한 상태에서 `/products/review` 경로로 이동해도, **모달 창이 뜨면서 기본 페이지는 유지**됩니다.

---

### 3. **가로채기 경로 설정 예시**

#### `/products/page.js` (기본 페이지)
```javascript
export default function ProductsPage() {
  return (
    <div>
      <h1>제품 목록</h1>
      <p>원하는 제품을 선택하세요.</p>
    </div>
  );
}
```

#### `/products/(modals)/review/page.js` (가로채기 모달 페이지)
```javascript
export default function ReviewModal() {
  return (
    <div style={{ background: 'rgba(0, 0, 0, 0.5)', padding: '20px' }}>
      <h2>리뷰 작성</h2>
      <p>이 제품에 대한 리뷰를 남겨주세요!</p>
    </div>
  );
}
```

- `/products` 페이지에 있을 때 `/products/review`로 이동하면 페이지 전체가 바뀌지 않고, **모달 창**만 나타납니다.

---

### 4. **레이아웃에서 가로채기 적용하기**

레이아웃을 사용하면 경로 가로채기를 **더 세밀하게 제어**할 수 있습니다.

#### 예제: `/products/layout.js`
```javascript
export default function ProductsLayout({ children, modals }) {
  return (
    <div>
      {children}
      {modals}
    </div>
  );
}
```

- **`{children}`**은 기본 페이지를 렌더링하고,  
- **`{modals}`**는 모달 창과 같은 가로채기 경로를 렌더링합니다.

---

### 5. **사용 예시: 모달 기반 네비게이션**

#### 예제: `/products/page.js`에서 버튼 클릭 시 모달 열기
```javascript
'use client';

import { useRouter } from 'next/navigation';

export default function ProductsPage() {
  const router = useRouter();

  const openReviewModal = () => {
    router.push('/products/review');
  };

  return (
    <div>
      <h1>제품 목록</h1>
      <button onClick={openReviewModal}>리뷰 작성하기</button>
    </div>
  );
}
```

- 사용자가 **리뷰 작성하기** 버튼을 클릭하면 `/products/review` 경로로 이동하고 모달 창이 뜹니다.
- **브라우저의 뒤로 가기 버튼**을 누르면 모달이 닫히고, `/products` 페이지로 돌아옵니다.

---

### 6. **SEO와 사용자 경험 최적화**

경로 가로채기를 사용하면 **사용자 경험을 개선**할 수 있습니다.  
- 예를 들어, 사용자가 모달 창을 열었다가 닫더라도 **페이지 상태가 유지**됩니다.
- 또한, Next.js는 **모달을 서버 측에서 렌더링**할 수 있어 SEO에도 긍정적인 영향을 줄 수 있습니다.

---

### 7. **에러 처리와 경로 가로채기**

가로채기 경로에서 문제가 발생할 경우, **에러 경계(Error Boundary)**를 사용해 적절한 처리가 가능합니다.

#### 예제: 에러 처리 적용
```javascript
export default function ProductsLayout({ children, modals }) {
  return (
    <div>
      {children}
      {modals || <p>모달을 불러오는 중 오류가 발생했습니다.</p>}
    </div>
  );
}
```

---

### 8. **정리: 경로 가로채기 활용 팁**  
- **모달 창, 알림 팝업, 확인 메시지** 등 임시 UI에 유용합니다.
- **페이지 전환 없이 상태를 유지**하면서 사용자 경험을 향상시킬 수 있습니다.
- 가로채기 기능은 **SEO와 서버 렌더링(SSR)**에도 활용할 수 있습니다.
- **`useRouter`**를 사용해 클라이언트 측에서 손쉽게 경로를 제어할 수 있습니다.

---

경로 가로채기를 사용하면 **더 자연스러운 사용자 경험과 부드러운 네비게이션**을 구현할 수 있습니다. 복잡한 UI도 페이지 리로드 없이 관리할 수 있어, 유연한 애플리케이션 설계에 큰 도움이 됩니다! 🚀
