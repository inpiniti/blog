---
title: 미들웨어(Middleware)
---

미들웨어는 **HTTP 요청과 응답 사이에 위치하여**, 특정 요청을 가로채거나 조작할 수 있는 기능입니다. Next.js에서는 **페이지로 요청이 들어오기 전에** 미들웨어가 실행되어, **인증 처리, 리다이렉트, 캐싱** 등 여러 작업을 수행할 수 있습니다.

---

### 1. **미들웨어의 기본 구조**

미들웨어는 **`middleware.js`** 또는 **`middleware.ts`** 파일을 프로젝트 루트에 만들어 사용합니다.

#### 예제: 기본 미들웨어
```javascript
// /middleware.js
import { NextResponse } from 'next/server';

export function middleware(request) {
  console.log('미들웨어가 실행되었습니다!');
  return NextResponse.next();
}
```

- **`middleware` 함수**는 모든 요청에 대해 실행됩니다.
- **`NextResponse.next()`**는 요청을 계속 진행시키고, 페이지를 렌더링합니다.

---

### 2. **특정 경로에만 미들웨어 적용하기**

`matcher`를 사용해 **특정 경로**에만 미들웨어를 적용할 수 있습니다.

#### 예제: 특정 경로 매칭
```javascript
export const config = {
  matcher: ['/about/:path*', '/dashboard/:path*'],
};
```

- `/about`이나 `/dashboard`로 들어오는 요청에만 미들웨어가 실행됩니다.

---

### 3. **리다이렉트 처리하기**

미들웨어를 사용해 사용자를 다른 페이지로 **리다이렉트**할 수 있습니다.

#### 예제: 로그인 여부에 따른 리다이렉트
```javascript
import { NextResponse } from 'next/server';

export function middleware(request) {
  const loggedIn = false; // 임의로 로그인 상태를 설정
  if (!loggedIn) {
    return NextResponse.redirect(new URL('/login', request.url));
  }
  return NextResponse.next();
}
```

- 사용자가 로그인되어 있지 않으면 **`/login`** 페이지로 리다이렉트합니다.

---

### 4. **쿠키를 사용한 인증 처리**

미들웨어에서 **쿠키**를 사용해 사용자의 인증 상태를 확인할 수 있습니다.

#### 예제: 쿠키로 인증 확인
```javascript
import { NextResponse } from 'next/server';

export function middleware(request) {
  const token = request.cookies.get('authToken');
  if (!token) {
    return NextResponse.redirect(new URL('/login', request.url));
  }
  return NextResponse.next();
}
```

- **`authToken`** 쿠키가 없으면 로그인 페이지로 리다이렉트됩니다.

---

### 5. **헤더 조작하기**

미들웨어를 통해 **요청 또는 응답 헤더**를 수정할 수 있습니다.

#### 예제: 응답 헤더 추가
```javascript
import { NextResponse } from 'next/server';

export function middleware(request) {
  const response = NextResponse.next();
  response.headers.set('X-Custom-Header', 'HelloWorld');
  return response;
}
```

- 모든 응답에 **`X-Custom-Header`** 헤더가 추가됩니다.

---

### 6. **미들웨어와 API 연동**

미들웨어에서 **API 요청**을 가로채거나 데이터를 조작할 수 있습니다.

#### 예제: API 요청 로그 기록
```javascript
export function middleware(request) {
  if (request.nextUrl.pathname.startsWith('/api')) {
    console.log('API 요청 감지:', request.nextUrl.pathname);
  }
  return NextResponse.next();
}
```

- **API 경로로의 요청**을 감지하여 로그를 남깁니다.

---

### 7. **정적 파일 처리와 미들웨어 예외**

정적 파일(예: **`/public`** 디렉터리의 파일)에 대한 요청은 기본적으로 미들웨어에서 **예외 처리**됩니다.  
미들웨어가 정적 파일 요청에 영향을 주지 않도록 설계되었기 때문입니다.

---

### 8. **에러 처리와 미들웨어**

미들웨어 내부에서도 **예외 처리**를 통해 오류에 대응할 수 있습니다.

#### 예제: 에러 처리
```javascript
export function middleware(request) {
  try {
    // 일부 로직 실행
    throw new Error('문제가 발생했습니다!');
  } catch (error) {
    return new Response(error.message, { status: 500 });
  }
}
```

- 오류가 발생하면 **500 에러**와 함께 오류 메시지를 반환합니다.

---

### 9. **미들웨어 사용 시 주의점**

- 미들웨어는 페이지 렌더링 전에 실행되므로, **최대한 빠르게 처리**하는 것이 좋습니다.
- **대규모 연산**이나 **느린 네트워크 요청**은 피하는 것이 좋습니다.
- 정적 파일 요청에는 미들웨어가 **적용되지 않습니다**.

---

### **정리**

- **미들웨어**는 **인증, 리다이렉트, 헤더 조작** 등 서버 측 요청을 유연하게 처리할 수 있습니다.
- **`matcher`**를 사용해 특정 경로에만 미들웨어를 적용할 수 있습니다.
- **쿠키와 헤더**를 활용한 인증이나 데이터 처리도 가능합니다.
- 미들웨어를 통해 **더 나은 보안과 사용자 경험**을 제공할 수 있습니다.

미들웨어를 잘 활용하면 **사용자 인증, 로그 관리, 접근 제어** 등을 효과적으로 구현할 수 있어, 보다 안정적이고 유연한 웹 애플리케이션을 개발할 수 있습니다! 🚀
