---
title: 국제화(i18n, Internationalization)
---

**i18n(Internationalization)**은 여러 **언어와 지역**을 지원하는 애플리케이션을 만드는 것을 의미합니다. Next.js는 이를 위해 **언어별 경로, 자동 리디렉션, 서브도메인 지원** 등의 기능을 제공합니다.

---

### 1. **국제화 설정하기**

국제화를 사용하려면 **`next.config.js`** 파일에 필요한 설정을 추가해야 합니다.

#### 예제: 기본 국제화 설정
```javascript
// next.config.js
module.exports = {
  i18n: {
    locales: ['en', 'ko', 'fr'], // 지원하는 언어 목록
    defaultLocale: 'en', // 기본 언어 설정
  },
};
```

- **`locales`**: 지원할 언어 목록을 설정합니다.
- **`defaultLocale`**: 사용자가 특정 언어를 선택하지 않았을 때 사용할 **기본 언어**를 설정합니다.

---

### 2. **언어별 경로 생성하기**

Next.js는 언어별로 **경로를 자동으로 생성**합니다. 예를 들어:
- **`/about`** 페이지는 영어일 때 **`/en/about`** 경로로 접근합니다.
- 한국어일 때는 **`/ko/about`**로 접근합니다.

---

### 3. **자동 리디렉션 처리**

Next.js는 **브라우저의 언어 설정**을 감지하여 **자동으로 적절한 언어로 리디렉션**합니다.

#### 예제: 자동 리디렉션 활성화
```javascript
// next.config.js
module.exports = {
  i18n: {
    locales: ['en', 'ko', 'fr'],
    defaultLocale: 'en',
    localeDetection: true, // 브라우저 언어 감지 및 리디렉션 활성화
  },
};
```

- 사용자가 **브라우저 언어**를 **`ko`**로 설정했다면 `/about`으로 들어갈 때 **`/ko/about`**으로 리디렉션됩니다.

---

### 4. **언어 변경 기능 구현하기**

언어를 변경할 수 있는 **링크나 버튼**을 만들어 사용자가 직접 언어를 선택할 수 있습니다.

#### 예제: `Link`를 사용한 언어 변경
```javascript
import Link from 'next/link';
import { useRouter } from 'next/router';

export default function LanguageSwitcher() {
  const router = useRouter();
  const { locales, locale, pathname } = router;

  return (
    <div>
      {locales.map((loc) => (
        <Link key={loc} href={pathname} locale={loc}>
          <button disabled={locale === loc}>{loc}</button>
        </Link>
      ))}
    </div>
  );
}
```

- 이 코드는 현재 페이지에서 언어를 **변경할 수 있는 버튼**을 생성합니다.
- **`router`** 객체를 사용해 현재 경로와 언어를 가져옵니다.

---

### 5. **서브도메인별 언어 지원**

Next.js는 **서브도메인별로 언어**를 구분할 수도 있습니다. 예를 들어, **`en.example.com`**은 영어를, **`ko.example.com`**은 한국어를 제공할 수 있습니다.

#### 예제: 서브도메인 설정
```javascript
// next.config.js
module.exports = {
  i18n: {
    locales: ['en', 'ko'],
    defaultLocale: 'en',
    domains: [
      {
        domain: 'example.com',
        defaultLocale: 'en',
      },
      {
        domain: 'ko.example.com',
        defaultLocale: 'ko',
      },
    ],
  },
};
```

- 사용자가 **ko.example.com**에 접속하면 자동으로 **한국어 페이지**가 로드됩니다.

---

### 6. **정적 페이지와 국제화 지원**

정적 사이트를 빌드할 때 Next.js는 각 언어별로 **정적 HTML 파일**을 생성합니다.  
이로 인해 빠른 로딩 속도를 유지하면서도 다양한 언어를 지원할 수 있습니다.

#### 예제: `getStaticProps`에서 언어 데이터 사용
```javascript
export async function getStaticProps({ locale }) {
  const messages = await import(`../messages/${locale}.json`);
  return {
    props: {
      messages: messages.default,
    },
  };
}
```

- 이 코드는 **언어별 JSON 파일**을 불러와 페이지에서 사용할 수 있게 합니다.

---

### 7. **Next.js와 번역 라이브러리 사용하기**

**`next-i18next`** 같은 라이브러리를 사용하면 더 쉽게 다국어 지원을 구현할 수 있습니다. 이 라이브러리는 번역 파일을 관리하고, 컴포넌트에 번역 데이터를 주입합니다.

---

### 8. **언어 감지 비활성화하기**

특정 상황에서는 **언어 감지 기능**을 비활성화하고 싶을 수도 있습니다.

#### 예제: 언어 감지 비활성화
```javascript
// next.config.js
module.exports = {
  i18n: {
    locales: ['en', 'ko'],
    defaultLocale: 'en',
    localeDetection: false, // 언어 감지 비활성화
  },
};
```

---

### **정리**

- **Next.js의 i18n** 기능은 다양한 언어와 지역별 콘텐츠를 손쉽게 지원합니다.
- 언어별 **경로 생성**, **자동 리디렉션**, **서브도메인 지원** 등 다양한 기능이 제공됩니다.
- **브라우저 언어 감지**를 통해 사용자에게 맞춤형 경험을 제공합니다.
- **`next-i18next`**와 같은 라이브러리와 결합해 더 강력한 국제화 기능을 구현할 수 있습니다.

국제화를 통해 **전 세계 사용자에게 더 나은 경험**을 제공하는 글로벌 애플리케이션을 구축해보세요! 🚀
