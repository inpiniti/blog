### 1. **페이지 (Pages)**
- **`pages/` 폴더**에 파일을 만들면 그 파일 이름이 URL 경로가 됩니다.  
  예를 들어, `pages/about.js` 파일을 만들면, `/about` 경로로 접속할 수 있어요.

- **기본 동작**은:
  - `index.js` 파일은 루트 경로(`/`)에 해당해요.
  - 페이지마다 컴포넌트를 정의하고, 그 컴포넌트가 해당 페이지를 보여줍니다.

#### 예제:
```javascript
// pages/index.js
export default function Home() {
  return <h1>홈페이지입니다!</h1>;
}
```

### 2. **레이아웃 (Layouts)**
- 레이아웃은 여러 페이지에서 **공통으로 사용하는 UI**를 한 곳에서 관리하기 위한 구조입니다. 예를 들어, 모든 페이지에 같은 네비게이션 바가 필요할 때 레이아웃을 사용해요.

- **폴더 구조 예시:**
  ```
  /pages
    /about.js
    /dashboard.js
    /_app.js
  ```
  - `_app.js` 파일은 **전역 레이아웃**을 설정할 수 있는 곳입니다. 모든 페이지에 공통 레이아웃을 적용하고 싶을 때 사용해요.

#### 예제:
```javascript
// pages/_app.js
export default function MyApp({ Component, pageProps }) {
  return (
    <div>
      <nav>네비게이션 바</nav>
      <Component {...pageProps} />
    </div>
  );
}
```
위 코드에서는 모든 페이지에 `네비게이션 바`가 나타나고, 해당 페이지의 내용은 `<Component />`로 렌더링됩니다.

### 3. **동적 라우팅 (Dynamic Routing)**
- 파일 이름에 **대괄호([ ])**를 사용하면 동적 경로를 생성할 수 있어요.  
  예를 들어, `pages/post/[id].js` 파일을 만들면 `/post/1`, `/post/2` 등 다양한 URL을 처리할 수 있습니다.

#### 예제:
```javascript
// pages/post/[id].js
import { useRouter } from 'next/router';

export default function Post() {
  const router = useRouter();
  const { id } = router.query;

  return <h1>게시물 번호: {id}</h1>;
}
```

### 4. **폴더로 경로 구성하기**
- `pages/` 폴더 내에 폴더를 만들면 URL 구조를 더 체계적으로 구성할 수 있습니다.  
  예를 들어, `pages/blog/index.js`를 만들면 `/blog` 경로로 접근할 수 있어요.

---

이렇게 Next.js에서는 **페이지와 레이아웃을 통해 효율적으로 웹사이트를 구성**할 수 있어요!  
필요에 따라 **동적 경로**나 **공통 레이아웃**을 활용하면 프로젝트를 더 깔끔하게 관리할 수 있답니다. 😊
