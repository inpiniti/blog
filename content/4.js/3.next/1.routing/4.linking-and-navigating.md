---
title: Next.js에서 링크와 내비게이션 구성하기
---

Next.js에서는 페이지 간에 **링크 이동과 내비게이션**을 효율적으로 처리할 수 있는 여러 방법을 제공합니다.

---

### 1. **Link 컴포넌트로 페이지 이동하기**
- `next/link` 컴포넌트를 사용하면 다른 페이지로 빠르게 이동할 수 있어요.
- **일반적인 `<a>` 태그 대신 Link 컴포넌트를 쓰는 이유**는 성능 최적화 때문입니다. Link는 **클라이언트 사이드 내비게이션**을 사용해서 페이지를 새로고침 없이 빠르게 이동합니다.

#### 예제:
```javascript
import Link from 'next/link';

export default function Home() {
  return (
    <div>
      <h1>홈페이지</h1>
      <Link href="/about">About 페이지로 이동</Link>
    </div>
  );
}
```
- 위 예제에서 "About 페이지로 이동"을 클릭하면 `/about` 페이지로 빠르게 이동합니다.

---

### 2. **프로그래밍 방식으로 내비게이션 처리 (useRouter 사용)**
- `next/router`의 **`useRouter` 훅**을 사용하면 자바스크립트 코드로 페이지 이동을 제어할 수 있습니다.
- 예를 들어, **버튼 클릭 시** 특정 페이지로 이동하고 싶을 때 유용합니다.

#### 예제:
```javascript
import { useRouter } from 'next/router';

export default function Home() {
  const router = useRouter();

  const goToAbout = () => {
    router.push('/about');
  };

  return (
    <div>
      <h1>홈페이지</h1>
      <button onClick={goToAbout}>About 페이지로 이동</button>
    </div>
  );
}
```
- 버튼을 클릭하면 `/about` 페이지로 이동합니다.

---

### 3. **Link에 여러 속성 사용하기**
- **`replace`**: 페이지 기록을 덮어씁니다. (뒤로가기 했을 때 이동이 취소됨)  
- **`scroll`**: 이동 후 페이지가 최상단으로 스크롤되도록 설정합니다.  
- **`prefetch`**: 사용자가 링크에 마우스를 올려놓을 때 미리 페이지를 로드합니다(Next.js의 기본 기능).

#### 예제:
```javascript
<Link href="/profile" replace scroll={false}>
  프로필 페이지로 이동
</Link>
```
- 여기서는 `replace`가 적용되어, 해당 페이지 방문 기록이 남지 않습니다.

---

### 4. **라우팅 메소드: `push`와 `replace` 차이**
- **`router.push()`**: 새 페이지를 방문 기록에 추가합니다.  
- **`router.replace()`**: 현재 페이지 기록을 덮어씁니다. (뒤로 가기 불가능)

#### 예제:
```javascript
router.push('/dashboard'); // 기록에 추가
router.replace('/dashboard'); // 기록 덮어쓰기
```

---

### 5. **페이지 리다이렉션 처리**
- `next.config.js` 파일에서 리다이렉션을 정의할 수 있습니다. 예를 들어, `/old-route`로 접근하면 자동으로 `/new-route`로 이동하게 만들 수 있습니다.

#### 예제 (next.config.js):
```javascript
module.exports = {
  async redirects() {
    return [
      {
        source: '/old-route',
        destination: '/new-route',
        permanent: true,
      },
    ];
  },
};
```
- **`permanent: true`**는 301 리다이렉션(영구 이동)을 의미합니다.

---

### 6. **동적 경로로 이동하기**
- 동적 페이지(예: `/post/[id]`)로 이동할 때는 객체 형태로 경로를 설정해야 합니다.

#### 예제:
```javascript
router.push({
  pathname: '/post/[id]',
  query: { id: '123' },
});
```
- `/post/123` 페이지로 이동합니다.

---

### 요약
- **Link** 컴포넌트는 빠르고 최적화된 페이지 이동을 제공합니다.
- **useRouter** 훅을 사용하면 프로그래밍 방식으로 내비게이션을 제어할 수 있습니다.
- **리다이렉션과 동적 경로 이동**도 쉽게 설정할 수 있어 다양한 내비게이션 시나리오를 처리할 수 있습니다.

이렇게 Next.js의 링크와 내비게이션 기능을 활용하면 더 빠르고 유연한 사용자 경험을 제공할 수 있습니다! 😊
