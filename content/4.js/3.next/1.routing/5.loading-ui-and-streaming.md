---
title: Next.js에서 로딩 UI와 스트리밍 사용하기
---

Next.js에서는 사용자가 페이지를 로드할 때 더 나은 경험을 제공하기 위해 **로딩 UI**와 **스트리밍** 기능을 지원합니다. 아래는 이 기능들의 주요 개념과 사용 방법입니다.

---

### 1. **로딩 UI 사용하기**  
로딩 중에 사용자가 빈 화면을 보지 않도록 **일시적인 로딩 상태를 표시하는 UI**를 제공할 수 있습니다. Next.js에서는 `loading.js` 파일을 활용하여 구현합니다.

#### 예제: 로딩 UI 구성
- 특정 라우트 그룹에 로딩 화면을 추가하려면 해당 경로 아래에 **`loading.js` 파일**을 만들어 사용합니다.

```
/app
  /dashboard
    loading.js
    page.js
```

#### `loading.js` 예제:
```javascript
export default function Loading() {
  return <p>로딩 중입니다...</p>;
}
```
- 사용자가 `/dashboard` 페이지를 방문할 때, 페이지가 준비되기 전까지 **"로딩 중입니다..."** 메시지가 표시됩니다.

---

### 2. **스트리밍과 점진적 렌더링 (Streaming and Progressive Rendering)**  
Next.js는 서버에서 페이지를 부분적으로 생성하고, 완성된 부분부터 먼저 클라이언트로 전송하는 **스트리밍** 기능을 지원합니다. 이를 통해 페이지 로딩 시간을 줄이고, 중요한 콘텐츠를 빠르게 보여줄 수 있습니다.

#### 예제: 페이지 스트리밍
- 페이지 내부에서 컴포넌트가 데이터를 불러오는 동안, 우선 다른 요소를 먼저 렌더링할 수 있습니다.
- **`Suspense`** 컴포넌트는 특정 UI가 준비될 때까지 대체 UI(로딩 메시지 등)를 표시해줍니다.

```javascript
import { Suspense } from 'react';
import UserProfile from './UserProfile';

export default function Page() {
  return (
    <div>
      <h1>대시보드</h1>
      <Suspense fallback={<p>사용자 프로필을 불러오는 중...</p>}>
        <UserProfile />
      </Suspense>
    </div>
  );
}
```
- 이 예제에서는 `<UserProfile />` 컴포넌트가 준비될 때까지 **"사용자 프로필을 불러오는 중..."** 메시지가 표시됩니다.

---

### 3. **`ErrorBoundary`로 오류 처리하기**  
스트리밍 중 문제가 발생할 수 있기 때문에, 오류가 발생했을 때 사용자에게 **적절한 메시지**를 보여줄 수 있습니다. 이때 **`ErrorBoundary`**를 사용하면 유용합니다.

#### 예제: 오류 처리
```javascript
import { Suspense } from 'react';

function ErrorFallback({ error }) {
  return <p>오류가 발생했습니다: {error.message}</p>;
}

export default function Page() {
  return (
    <ErrorBoundary FallbackComponent={ErrorFallback}>
      <Suspense fallback={<p>로딩 중...</p>}>
        <UserProfile />
      </Suspense>
    </ErrorBoundary>
  );
}
```
- **오류 발생 시** `"오류가 발생했습니다:..."` 메시지를 보여주며, 사용자는 문제를 인지할 수 있습니다.

---

### 4. **스트리밍의 장점**
- **빠른 첫 화면 제공**: 중요한 UI를 우선 렌더링하여 사용자 경험을 개선합니다.
- **네트워크 병목 완화**: 대용량 페이지도 빠르게 스트리밍할 수 있습니다.
- **점진적 데이터 로딩**: 서버에서 데이터를 다 불러오기 전에도 일부분을 먼저 보여줍니다.

---

### 요약  
- **`loading.js`**로 로딩 중인 UI를 표시할 수 있습니다.  
- **`Suspense`와 스트리밍**을 활용하면 중요한 부분을 빠르게 렌더링하고 나머지 콘텐츠를 점진적으로 로드할 수 있습니다.  
- **`ErrorBoundary`**를 통해 예상치 못한 오류도 안전하게 처리할 수 있습니다.

Next.js의 **로딩 UI와 스트리밍 기능**을 잘 활용하면 성능이 좋고 매끄러운 사용자 경험을 제공할 수 있습니다! 🚀
