---
title: Next.js에서 에러 처리하기 (Error Handling)
---

Next.js는 페이지나 컴포넌트에서 발생하는 **오류**를 효과적으로 처리할 수 있도록 다양한 기능을 제공합니다. 아래는 **에러 처리 방법과 예제**들입니다.

---

### 1. **기본 에러 페이지**  
Next.js는 기본적으로 서버나 클라이언트 오류가 발생할 경우, 자동으로 **404 (페이지 없음)**과 **500 (서버 오류)** 페이지를 제공합니다.

- **404 페이지**: 사용자가 존재하지 않는 경로로 접근했을 때 표시됩니다.  
- **500 페이지**: 서버 측에서 예상치 못한 오류가 발생했을 때 표시됩니다.

하지만 필요에 따라 **커스텀 에러 페이지**를 만들 수도 있습니다.

---

### 2. **커스텀 404 페이지 만들기**  
`/app/not-found.js` 파일을 만들면 404 오류가 발생할 때 표시되는 페이지를 커스터마이즈할 수 있습니다.

#### 예제: `not-found.js`
```javascript
export default function NotFound() {
  return <h1>페이지를 찾을 수 없습니다 😢</h1>;
}
```
- 사용자가 없는 경로로 접근하면 **"페이지를 찾을 수 없습니다"** 메시지를 보여줍니다.

---

### 3. **커스텀 500 페이지 만들기**  
`/app/error.js` 파일을 생성하면 서버 오류가 발생할 때 표시되는 500 페이지를 정의할 수 있습니다.

#### 예제: `error.js`
```javascript
export default function Error() {
  return <h1>서버에 문제가 발생했습니다 😥</h1>;
}
```
- 이 페이지는 서버 오류가 발생했을 때 사용자에게 보여집니다.

---

### 4. **`notFound()` 함수로 특정 조건에서 404 반환하기**  
Next.js에서는 컴포넌트나 페이지 내에서 특정 조건이 만족되면 **`notFound()`** 함수를 호출해 404 페이지로 리다이렉트할 수 있습니다.

#### 예제:
```javascript
import { notFound } from 'next/navigation';

export default function UserProfile({ user }) {
  if (!user) {
    notFound(); // 유저가 없으면 404 페이지로 이동
  }

  return <h1>{user.name}의 프로필</h1>;
}
```
- 데이터가 없을 때 404 페이지로 이동시켜줍니다.

---

### 5. **`ErrorBoundary`를 사용한 컴포넌트 레벨 오류 처리**  
React의 **`ErrorBoundary`**를 사용하면 특정 컴포넌트에서 발생하는 오류를 잡아 적절한 UI를 보여줄 수 있습니다. 

#### 예제:
```javascript
import { ErrorBoundary } from 'react-error-boundary';

function ErrorFallback({ error }) {
  return <p>문제가 발생했습니다: {error.message}</p>;
}

export default function Page() {
  return (
    <ErrorBoundary FallbackComponent={ErrorFallback}>
      <ProblematicComponent />
    </ErrorBoundary>
  );
}
```
- 오류가 발생하면 `"문제가 발생했습니다:..."` 메시지가 나타납니다.

---

### 6. **페이지 리디렉션과 에러 핸들링 통합하기**  
`next/navigation`의 **`redirect()`**를 사용해 사용자를 다른 페이지로 보낼 수도 있습니다.

#### 예제:
```javascript
import { redirect } from 'next/navigation';

export default function AdminPage({ user }) {
  if (!user.isAdmin) {
    redirect('/not-authorized'); // 권한이 없을 때 리다이렉트
  }

  return <h1>관리자 페이지</h1>;
}
```

---

### 7. **API 경로에서의 에러 처리**  
API 라우트에서도 에러 처리가 가능합니다. 오류가 발생하면 적절한 **HTTP 상태 코드와 메시지**를 반환하세요.

#### 예제:
```javascript
export default function handler(req, res) {
  try {
    // API 로직...
    res.status(200).json({ message: '성공!' });
  } catch (error) {
    res.status(500).json({ error: '서버 오류가 발생했습니다.' });
  }
}
```

---

### 요약  
- **404와 500 페이지**를 커스터마이즈해 사용자에게 더 나은 오류 메시지를 제공합니다.  
- **`notFound()` 함수**로 특정 조건에서 404로 리다이렉트할 수 있습니다.  
- **`ErrorBoundary`**를 사용하면 컴포넌트 단위에서 오류를 잡고 처리할 수 있습니다.  
- **API 경로**에서도 적절한 오류 처리를 통해 안정성을 높일 수 있습니다.

이렇게 Next.js의 에러 처리 기능을 활용하면 **더 직관적이고 안정적인 웹 애플리케이션**을 만들 수 있습니다! 🚀
