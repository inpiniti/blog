---
title: Next.js에서 리디렉션(redirecting) 처리하기
---

리디렉션은 사용자를 특정 경로에서 다른 경로로 **자동으로 이동**시키는 것을 의미합니다. Next.js에서는 **서버와 클라이언트** 양쪽에서 리디렉션을 쉽게 설정할 수 있습니다.

---

### 1. **next.config.js를 사용한 리디렉션 설정**  
Next.js의 **`next.config.js`** 파일에서 영구적 또는 임시적인 리디렉션을 설정할 수 있습니다.

#### 예제: next.config.js  
```javascript
module.exports = {
  async redirects() {
    return [
      {
        source: '/old-route',
        destination: '/new-route',
        permanent: true, // 301: 영구 리디렉션
      },
      {
        source: '/temporary',
        destination: '/temporary-redirect',
        permanent: false, // 302: 임시 리디렉션
      },
    ];
  },
};
```

- **`permanent: true`**: 301 리디렉션(영구 이동)  
- **`permanent: false`**: 302 리디렉션(임시 이동)  

이 설정은 **서버 측에서 리디렉션**이 일어나며, SEO(검색 엔진)에도 반영됩니다.

---

### 2. **클라이언트 측 리디렉션: `redirect()` 사용하기**  
Next.js에서는 클라이언트 측에서 사용자를 다른 페이지로 이동시킬 때 **`redirect()`** 함수를 사용할 수 있습니다.

#### 예제:
```javascript
import { redirect } from 'next/navigation';

export default function Page() {
  redirect('/new-home'); // 페이지 로드 시 '/new-home'으로 이동
  return <p>이 메시지는 표시되지 않습니다.</p>;
}
```
- 이 함수는 **페이지 로드 시 즉시 리디렉션**을 실행합니다.

---

### 3. **조건부 리디렉션: 서버 측에서 리디렉션 처리**  
Next.js의 **서버 컴포넌트**에서 특정 조건에 따라 리디렉션을 할 수 있습니다.

#### 예제:
```javascript
import { redirect } from 'next/navigation';

export default function AdminPage({ user }) {
  if (!user.isAdmin) {
    redirect('/not-authorized'); // 관리자 권한이 없을 경우 리디렉션
  }

  return <h1>관리자 페이지</h1>;
}
```
- 사용자가 관리자 권한이 없을 때 `/not-authorized` 페이지로 이동합니다.

---

### 4. **API 라우트에서 리디렉션 처리하기**  
API 라우트에서도 리디렉션을 설정할 수 있습니다.

#### 예제: API 리디렉션
```javascript
export default function handler(req, res) {
  res.writeHead(307, { Location: '/new-api-endpoint' });
  res.end();
}
```
- **307 상태 코드**는 임시 리디렉션을 의미합니다.

---

### 5. **리디렉션과 SEO**  
- **301 영구 리디렉션**은 검색 엔진에 반영되어 기존 경로가 새로운 경로로 업데이트됩니다.
- **302 임시 리디렉션**은 기존 경로가 유지되며, 임시로 다른 페이지로 이동시킬 때 사용합니다.

---

### 요약  
- **`next.config.js`**에서 리디렉션을 설정하면 서버 측에서 **301 또는 302** 리디렉션이 가능합니다.  
- **`redirect()`** 함수를 사용하면 **클라이언트 측에서 즉시 리디렉션**이 가능합니다.  
- API 라우트에서도 **HTTP 상태 코드**를 사용해 리디렉션을 처리할 수 있습니다.  
- SEO를 고려할 때는 **301과 302 리디렉션**을 상황에 맞게 사용하는 것이 중요합니다.

이렇게 Next.js의 리디렉션 기능을 활용하면 더 유연하고 직관적인 네비게이션 경험을 제공할 수 있습니다! 🚀
