---
title: Next.js의 라우트 그룹(Route Groups)
---

라우트 그룹(Route Groups)은 **경로와 URL 구조를 깔끔하게 관리**하고, 경로에 영향을 주지 않으면서 코드 구조를 개선할 수 있는 기능입니다. 이 기능은 특히 대규모 애플리케이션에서 **경로 모듈화를 용이하게** 만들어 줍니다.

---

### 1. **라우트 그룹의 기본 사용법**  
라우트 그룹은 디렉터리 이름에 **`(`와 `)`**를 사용하여 생성합니다. 이렇게 정의된 그룹은 실제 URL 경로에 **영향을 주지 않습니다**.

#### 예제: 라우트 그룹 구성
```
/app
  /(marketing)        # 라우트 그룹 생성 (URL에 영향 없음)
    home/page.js      # /home 경로에 매핑
    about/page.js     # /about 경로에 매핑
  /(dashboard)        # 또 다른 라우트 그룹
    user/page.js      # /user 경로에 매핑
```

위의 예제에서 **`(marketing)`과 `(dashboard)`**는 디렉터리 그룹 이름일 뿐, **URL에는 포함되지 않습니다.**

---

### 2. **라우트 그룹을 사용하는 이유**  
1. **코드 구조 정리**: 관련된 페이지들을 하나의 그룹에 모아 **더 깔끔한 디렉터리 구조**를 유지할 수 있습니다.
2. **레이아웃 재사용**: 그룹 내의 여러 페이지에서 **공통 레이아웃**을 쉽게 적용할 수 있습니다.
3. **URL에 영향 없음**: 그룹 이름은 **사용자 URL에 노출되지 않아** 경로에 영향을 주지 않습니다.

---

### 3. **라우트 그룹과 레이아웃(Layout) 연결**  
라우트 그룹에 공통 레이아웃을 지정할 수 있습니다. **`layout.js`** 파일을 통해 그룹 내의 모든 페이지에 동일한 레이아웃을 적용합니다.

#### 예제: 그룹별 레이아웃 사용
```
/app
  /(marketing)
    layout.js        # 마케팅 페이지 전용 레이아웃
    home/page.js
    about/page.js
  /(dashboard)
    layout.js        # 대시보드 페이지 전용 레이아웃
    user/page.js
```

**`(marketing)` 그룹의 `layout.js`**:
```javascript
export default function MarketingLayout({ children }) {
  return (
    <div>
      <header>마케팅 헤더</header>
      <main>{children}</main>
    </div>
  );
}
```
- **모든 마케팅 페이지**에 공통 레이아웃을 제공하며, 페이지마다 반복적인 레이아웃 설정이 필요하지 않습니다.

---

### 4. **비공개 경로와 라우트 그룹**  
특정 그룹의 페이지를 비공개로 만들고, **인증된 사용자만 접근할 수 있도록** 할 수 있습니다.

#### 예제: 인증이 필요한 대시보드
```javascript
import { redirect } from 'next/navigation';

export default function DashboardLayout({ children, user }) {
  if (!user) {
    redirect('/login'); // 로그인되지 않은 경우 리디렉트
  }
  return <div>{children}</div>;
}
```
- **`(dashboard)`** 그룹에 접근하려면 인증이 필요하며, 그렇지 않으면 **로그인 페이지**로 리디렉션됩니다.

---

### 5. **라우트 그룹 중첩 사용**  
라우트 그룹은 **여러 계층**으로 중첩할 수도 있습니다.

#### 예제:
```
/app
  /(marketing)
    /(blog)
      post/page.js    # /post 경로
  /(dashboard)
    /(settings)
      profile/page.js # /profile 경로
```

이렇게 **중첩된 그룹**을 사용해도 URL은 여전히 `/post`나 `/profile`로 간단하게 유지됩니다.

---

### 6. **옵셔널 그룹 사용**  
경로를 동적으로 처리하려면 **옵셔널 라우트 그룹**을 사용할 수 있습니다. 

#### 예제: 옵션 경로 그룹
```
/app
  /[lang]
    (marketing)
      home/page.js  # /en/home 또는 /ko/home 등으로 접근 가능
```
- **옵셔널 파라미터** `[lang]`을 통해 `/en/home`과 같은 다국어 경로를 관리할 수 있습니다.

---

### 요약  
- **라우트 그룹**은 **디렉터리 구조를 개선**하고, 경로를 깔끔하게 관리할 수 있도록 도와줍니다.  
- 그룹은 **URL에 영향을 주지 않으면서도** 레이아웃과 모듈화된 코드를 적용할 수 있습니다.  
- **공통 레이아웃**을 그룹에 쉽게 적용하고, **중첩 그룹**으로 더 복잡한 구조도 깔끔하게 처리할 수 있습니다.  
- 인증이 필요한 경로나 **옵셔널 경로**도 라우트 그룹으로 쉽게 구현 가능합니다.

이렇게 Next.js의 라우트 그룹을 사용하면 **더 깔끔하고 확장성 있는 애플리케이션**을 개발할 수 있습니다! 🚀
