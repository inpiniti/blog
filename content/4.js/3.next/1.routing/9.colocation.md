---
title: Colocation(콜로케이션)
---

**콜로케이션(Colocation)**은 **관련된 코드와 파일을 가까이 배치하여 관리**하는 개발 패턴입니다. 이 방식은 유지보수와 코드 이해도를 높여주며, Next.js에서는 **페이지, 컴포넌트, 스타일, 데이터 등을 함께 배치**하여 프로젝트를 효율적으로 구성하는 데 활용됩니다.

---

### 1. **콜로케이션의 기본 개념**  
콜로케이션에서는 **연관된 코드**를 같은 폴더나 가까운 위치에 모아둡니다. 예를 들어, 특정 페이지와 관련된 컴포넌트, 데이터 fetch 로직, 스타일 파일을 **같은 디렉터리**에 배치합니다.

#### 예제:
```
/app/products
  page.js           # Products 페이지
  components/
    ProductCard.js  # ProductCard 컴포넌트
  data/
    products.js     # 제품 목록 데이터
  styles.css        # 페이지 스타일
```
- **`page.js`**와 연관된 컴포넌트, 데이터, 스타일이 모두 **같은 폴더**에 모여있어 관리가 편리합니다.

---

### 2. **콜로케이션의 장점**  
- **더 나은 코드 가독성**: 연관된 코드가 한곳에 모여있어 찾기 쉽습니다.  
- **유지보수성 향상**: 필요한 모든 코드가 가까이 배치되어 수정과 유지보수가 용이합니다.  
- **코드 모듈화**: 각 페이지에 필요한 파일들을 따로 관리해 **코드 분리와 모듈화**를 쉽게 합니다.

---

### 3. **콜로케이션 예제: 폴더 구조**  
콜로케이션을 통해 파일을 다음과 같이 구성할 수 있습니다.

#### 예제: `Blog` 페이지 구조
```
/app/blog
  page.js            # Blog 메인 페이지
  components/
    BlogPost.js      # 개별 블로그 포스트 컴포넌트
    Comments.js      # 댓글 컴포넌트
  data/
    posts.js         # 포스트 데이터
  styles.css         # 블로그 페이지 스타일
```

**페이지 코드 (`page.js`)**:
```javascript
import BlogPost from './components/BlogPost';
import { posts } from './data/posts';

export default function BlogPage() {
  return (
    <div>
      <h1>블로그</h1>
      {posts.map((post) => (
        <BlogPost key={post.id} post={post} />
      ))}
    </div>
  );
}
```
- **BlogPage**는 필요한 컴포넌트와 데이터를 같은 폴더 내에서 쉽게 가져올 수 있습니다.

---

### 4. **스타일 파일의 콜로케이션**  
페이지 또는 컴포넌트와 관련된 스타일을 **같은 디렉터리**에 두어 관리할 수 있습니다. 이 패턴은 **글로벌 CSS 오염을 방지**하고, 코드 구조를 더욱 직관적으로 만듭니다.

#### 예제: 스타일 파일 적용
```javascript
import './styles.css';

export default function BlogPost({ post }) {
  return (
    <article className="post">
      <h2>{post.title}</h2>
      <p>{post.content}</p>
    </article>
  );
}
```

---

### 5. **데이터 로직의 콜로케이션**  
데이터 fetching 코드도 페이지와 가까운 위치에 배치하여 **관련성을 유지**합니다. Next.js의 **`fetch()`** 함수나 API 호출 로직을 같은 디렉터리 내에 둘 수 있습니다.

#### 예제: 데이터 로직의 콜로케이션
```
/app/users
  page.js         # 사용자 목록 페이지
  data/
    users.js      # 사용자 데이터 fetch 로직
```

**`users.js`**:
```javascript
export async function getUsers() {
  const res = await fetch('/api/users');
  return res.json();
}
```
**`page.js`**에서 가져오기:
```javascript
import { getUsers } from './data/users';

export default async function UsersPage() {
  const users = await getUsers();
  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

---

### 6. **Next.js의 파일 시스템 라우팅과 콜로케이션**  
Next.js의 **파일 시스템 기반 라우팅**과 콜로케이션은 잘 맞아떨어집니다. 페이지와 연관된 로직을 **디렉터리로 모듈화**하여 간결한 라우트 구성을 지원합니다.

---

### 7. **콜로케이션의 베스트 프랙티스**  
1. **작은 단위로 분리**: 페이지나 컴포넌트가 너무 커지지 않도록 적절히 쪼갭니다.  
2. **연관된 코드 묶기**: 한 페이지와 직접 연관된 컴포넌트, 스타일, 데이터만 함께 둡니다.  
3. **레이아웃과 그룹 활용**: 레이아웃을 사용할 때도 콜로케이션을 적용해 관련된 페이지를 함께 묶습니다.

---

### 요약  
- **콜로케이션(Colocation)**은 **관련된 코드와 파일을 가까이 배치**하는 개발 패턴입니다.  
- 유지보수와 코드 이해도를 높이며, Next.js의 **파일 시스템 라우팅**과 잘 맞아떨어집니다.  
- 컴포넌트, 데이터, 스타일 파일을 한곳에 모아 **코드의 가독성과 재사용성**을 높입니다.

Next.js의 콜로케이션을 활용하면 더 직관적이고 모듈화된 코드를 작성할 수 있습니다. **더 깔끔하고 관리하기 쉬운 프로젝트 구조**를 만들어보세요! 🚀
