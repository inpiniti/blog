## **1. 서버 액션(Server Actions)란?**

서버 액션은 **클라이언트와 서버 간의 데이터 전송을 쉽게 처리**할 수 있는 Next.js의 새로운 기능입니다. 서버에서 동작하는 함수들을 클라이언트에서 직접 호출할 수 있습니다.  
서버 액션을 사용하면 별도의 API 라우트 없이 서버 기능을 호출하고, **폼 제출이나 데이터 수정**을 간단하게 처리할 수 있습니다.

---

### **예제: 서버 액션 사용하기**

```javascript
"use server";

export async function createPost(data) {
  const res = await fetch("https://jsonplaceholder.typicode.com/posts", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });

  return res.json();
}
```

- **`"use server"`** 지시어를 사용해 서버에서 동작할 액션임을 표시합니다.
- 서버에서 **비동기 요청**을 처리할 수 있습니다.

---

### **클라이언트에서 서버 액션 호출하기**

서버 액션은 클라이언트에서 호출할 수 있습니다.

```javascript
"use client";

import { createPost } from "./actions";

export default function NewPostForm() {
  async function handleSubmit(event) {
    event.preventDefault();
    const formData = new FormData(event.target);
    const data = Object.fromEntries(formData);

    const result = await createPost(data); // 서버 액션 호출
    console.log(result);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="title" placeholder="Title" required />
      <button type="submit">Create Post</button>
    </form>
  );
}
```

- **폼 제출 시** 서버 액션을 호출하여 데이터를 전송합니다.
- API 라우트 없이 클라이언트에서 **서버 액션**을 호출할 수 있습니다.

---

## **2. 뮤테이션(Mutations)란?**

뮤테이션은 서버 액션을 사용해 **서버 데이터의 변경**을 처리하는 것을 의미합니다.  
예를 들어, **데이터 추가, 수정, 삭제** 등의 작업이 뮤테이션에 해당합니다. 서버 액션과 뮤테이션을 함께 사용하면, 클라이언트에서 데이터를 쉽게 조작할 수 있습니다.

---

### **예제: 서버 액션을 통한 데이터 삭제**

```javascript
"use server";

export async function deletePost(id) {
  const res = await fetch(`https://jsonplaceholder.typicode.com/posts/${id}`, {
    method: "DELETE",
  });

  if (!res.ok) {
    throw new Error("Failed to delete post");
  }

  return { success: true };
}
```

- 서버 액션을 사용해 **삭제 요청**을 처리합니다.

---

### **클라이언트에서 뮤테이션 실행하기**

```javascript
"use client";

import { deletePost } from "./actions";

export default function Post({ id }) {
  async function handleDelete() {
    try {
      await deletePost(id); // 서버 액션 호출
      alert("Post deleted successfully!");
    } catch (error) {
      console.error(error);
      alert("Failed to delete post.");
    }
  }

  return (
    <div>
      <h2>Post #{id}</h2>
      <button onClick={handleDelete}>Delete</button>
    </div>
  );
}
```

- 사용자가 **버튼을 클릭하면** 서버 액션을 통해 해당 게시물을 삭제합니다.

---

## **3. 서버 액션의 이점**

- **API 라우트가 필요 없음**: 클라이언트에서 서버 액션을 직접 호출합니다.
- **상태 관리 단순화**: 서버와 클라이언트 간의 데이터 전송을 쉽게 처리합니다.
- **보안 강화**: 서버 액션은 서버 측에서만 동작하므로, 중요한 로직을 안전하게 보호합니다.

---

## **4. 서버 액션과 캐싱**

서버 액션의 결과는 기본적으로 **캐시되지 않습니다**. 그러나, **중간에 캐시가 필요한 경우**에는 `fetch`와 같은 도구를 사용할 수 있습니다.

---

### **정리**

- 서버 액션은 **서버에서 동작하는 함수**를 클라이언트에서 쉽게 호출할 수 있게 합니다.
- 뮤테이션을 통해 클라이언트에서 **데이터의 추가, 수정, 삭제**를 간단하게 처리합니다.
- 별도의 API 라우트 없이 서버 액션을 호출해, **개발 경험과 성능을 최적화**합니다.

Next.js의 **서버 액션과 뮤테이션**을 잘 활용하면, 더 효율적이고 직관적인 애플리케이션을 만들 수 있습니다! 🚀
