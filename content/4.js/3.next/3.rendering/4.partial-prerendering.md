---
title: Partial Prerendering (부분 사전 렌더링)
description: Partial Prerendering(부분 사전 렌더링)은 Next.js에서 제공하는 최적화된 렌더링 방식입니다.
---

## **1. Partial Prerendering이란?**  

- 페이지의 일부를 **빌드 타임**에 미리 HTML로 렌더링합니다.  
- 나머지 데이터는 **클라이언트 측에서 동적으로 로드**됩니다.  
- 전체 페이지를 한 번에 렌더링하지 않고 필요한 부분만 **점진적으로 렌더링**하므로 **성능 최적화**에 유리합니다.

---

## **2. 언제 Partial Prerendering을 사용해야 할까?**  

- **일부 데이터가 동적일 때**: 유저에 따라 달라지는 데이터를 실시간으로 가져와야 할 때.  
- **초기 로딩을 빠르게 하고 싶을 때**: 전체 데이터를 렌더링하지 않고, 중요한 정보만 먼저 표시합니다.  
- **SEO 최적화가 필요한 부분만 렌더링할 때**: 검색 엔진 크롤러가 필요한 정보만 미리 렌더링해 둡니다.

---

## **3. 사용 예제: Static 부분과 동적 부분 조합**  

```javascript
// app/page.jsx
import { useState, useEffect } from 'react';

export default function HomePage({ staticData }) {
  const [dynamicData, setDynamicData] = useState(null);

  // 동적 데이터는 클라이언트에서 가져옵니다.
  useEffect(() => {
    fetch('/api/dynamic-data')
      .then((res) => res.json())
      .then((data) => setDynamicData(data));
  }, []);

  return (
    <div>
      <h1>부분 사전 렌더링 예제</h1>
      <p>사전 렌더링된 데이터: {staticData}</p>
      <p>동적으로 가져온 데이터: {dynamicData || '로딩 중...'}</p>
    </div>
  );
}

export async function getStaticProps() {
  const staticData = '사전 렌더링된 데이터입니다.';
  return { props: { staticData } };
}
```

### **코드 설명**  
1. **`getStaticProps`**: 이 함수는 빌드 시 실행되어 **사전 렌더링된 데이터를 제공**합니다.  
2. **`useEffect`**: 클라이언트에서 **동적 데이터**를 가져옵니다.  
3. 이 조합을 통해 중요한 데이터는 미리 렌더링되고, 덜 중요한 데이터는 **클라이언트에서 나중에 로드**됩니다.

---

## **4. Partial Prerendering의 이점**  

1. **초기 로딩 시간 단축**  
   - 중요한 정보만 먼저 표시해 **사용자 경험 개선**.  
2. **SEO 최적화**  
   - 검색 엔진에 중요한 콘텐츠는 미리 렌더링됩니다.  
3. **네트워크 리소스 절약**  
   - 필요할 때만 동적 데이터를 가져오므로 **불필요한 데이터 로딩을 줄임**.  
4. **사용자 맞춤형 콘텐츠 제공**  
   - 일부 데이터를 유저의 요청에 따라 실시간으로 렌더링할 수 있습니다.

---

## **5. Partial Prerendering과 Next.js의 다른 렌더링 방식 비교**  

| **렌더링 방식**            | **설명**                                          | **사용 시기**                                |
|---------------------------|--------------------------------------------------|---------------------------------------------|
| **Static Generation**      | 전체 페이지를 빌드 타임에 렌더링합니다.           | 자주 변하지 않는 정적 페이지에 적합        |
| **Server-side Rendering**  | 각 요청마다 서버에서 페이지를 렌더링합니다.        | 자주 변경되는 데이터가 필요할 때 사용     |
| **Partial Prerendering**   | 중요한 부분만 사전 렌더링하고, 나머지는 동적 처리 | 초기 성능 최적화와 동적 데이터가 필요할 때 |

---

## **6. 서버 구성 요소(Server Components)와의 조합**  

Next.js는 **서버 구성 요소**와 **클라이언트 구성 요소**를 조합해 Partial Prerendering을 더욱 강력하게 사용할 수 있습니다.

```javascript
// app/page.jsx
import ServerComponent from './ServerComponent';
import { useState } from 'react';

export default function HomePage() {
  const [clientData, setClientData] = useState(null);

  return (
    <div>
      <h1>서버와 클라이언트 구성 요소의 조합</h1>
      <ServerComponent />
      <button onClick={() => setClientData('동적 데이터')}>
        동적 데이터 로드
      </button>
      {clientData && <p>{clientData}</p>}
    </div>
  );
}
```

- **서버 구성 요소**는 중요한 데이터를 사전 렌더링합니다.  
- **클라이언트 구성 요소**는 사용자가 상호작용할 때 동적으로 데이터를 로드합니다.

---

## **7. 정리**  

**Partial Prerendering**은 페이지의 중요한 부분만 미리 렌더링하고, 나머지는 클라이언트에서 동적 처리해 성능을 최적화하는 기술입니다.  
- **SEO가 중요한 페이지의 일부만 미리 렌더링**할 때 유용합니다.  
- 사용자가 빠르게 콘텐츠를 확인할 수 있고, **동적 데이터는 나중에 로드**합니다.  
- **서버와 클라이언트 구성 요소**를 조합해 더 나은 사용자 경험을 제공합니다.  

이 방식을 활용하면 **빠른 초기 로딩 시간과 유연한 데이터 처리**를 동시에 할 수 있습니다! 🚀
