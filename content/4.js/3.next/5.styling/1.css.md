## **1. 글로벌 CSS(Global CSS)**  

Next.js에서는 **글로벌 CSS 파일**을 사용해 애플리케이션 전체에 스타일을 적용할 수 있습니다.  
> **주의**: 글로벌 CSS는 오직 `pages/_app.js` 파일에서만 import할 수 있습니다.

### **사용 방법**
```css
/* styles/global.css */
body {
  margin: 0;
  padding: 0;
  font-family: Arial, sans-serif;
}
```

```javascript
// pages/_app.js
import '../styles/global.css';

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />;
}
```

- **전역 스타일**이므로 모든 페이지에 적용됩니다.
- 스타일이 충돌할 수 있으므로 사용에 주의가 필요합니다.

---

## **2. CSS Modules**  

**CSS Modules**는 컴포넌트 단위로 **고유한 클래스 이름을 생성**해 스타일 충돌을 방지합니다.  
파일 이름에 **`.module.css`**를 사용하면 CSS Modules로 인식됩니다.

### **사용 방법**
```css
/* styles/Button.module.css */
.button {
  background-color: blue;
  color: white;
  padding: 10px;
  border-radius: 5px;
}
```

```javascript
// components/Button.js
import styles from '../styles/Button.module.css';

export default function Button() {
  return <button className={styles.button}>클릭!</button>;
}
```

- CSS 클래스가 **컴포넌트에 국한**되므로 스타일 충돌이 없습니다.
- **컴포넌트 단위로 재사용**하기 좋습니다.

---

## **3. Sass 사용하기**  

Next.js는 **Sass/SCSS**를 기본 지원합니다. Sass는 CSS에 **변수, 믹스인, 중첩 스타일** 등을 제공해 더 편리한 스타일 작성이 가능합니다.

### **설치 및 사용**
```bash
npm install sass
```

```scss
/* styles/variables.module.scss */
$primary-color: #3498db;

.button {
  background-color: $primary-color;
  padding: 10px;
  border-radius: 5px;
}
```

```javascript
// components/Button.js
import styles from '../styles/variables.module.scss';

export default function Button() {
  return <button className={styles.button}>Sass 버튼</button>;
}
```

- **CSS Modules**와 함께 사용할 수 있습니다.
- **복잡한 스타일** 작업에 적합합니다.

---

## **4. Styled JSX**  

**Styled JSX**는 Next.js에 내장된 **CSS-in-JS** 솔루션으로, 컴포넌트 내부에서 직접 스타일을 작성할 수 있습니다.

### **사용 방법**
```javascript
export default function Title() {
  return (
    <div>
      <h1>Styled JSX 사용하기</h1>
      <style jsx>{`
        h1 {
          color: purple;
          text-align: center;
        }
      `}</style>
    </div>
  );
}
```

- **컴포넌트 단위로 스타일을 작성**하므로 **범위가 자동으로 제한**됩니다.
- **CSS 파일 없이도** 스타일을 작성할 수 있습니다.

---

## **5. Tailwind CSS 사용하기**  

**Tailwind CSS**는 **유틸리티 클래스** 기반의 CSS 프레임워크로, 빠르게 스타일을 적용할 수 있습니다.

### **설치 및 설정**
```bash
npm install tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

```javascript
// tailwind.config.js
module.exports = {
  content: ['./pages/**/*.{js,ts,jsx,tsx}', './components/**/*.{js,ts,jsx,tsx}'],
  theme: {
    extend: {},
  },
  plugins: [],
};
```

```css
/* styles/globals.css */
@tailwind base;
@tailwind components;
@tailwind utilities;
```

```javascript
// components/Button.js
export default function Button() {
  return <button className="bg-blue-500 text-white p-2 rounded">Tailwind 버튼</button>;
}
```

- **빠르게 UI를 구성**하고 커스터마이징하기 쉽습니다.
- **다양한 유틸리티 클래스**로 복잡한 스타일도 쉽게 작성할 수 있습니다.

---

## **6. Emotion과 같은 CSS-in-JS 라이브러리 사용**  

Next.js에서는 **Emotion, Styled-Components**와 같은 **CSS-in-JS** 라이브러리도 사용할 수 있습니다.

### **Emotion 사용 예제**
```bash
npm install @emotion/react @emotion/styled
```

```javascript
/** @jsxImportSource @emotion/react */
import { css } from '@emotion/react';

const buttonStyle = css`
  background-color: hotpink;
  color: white;
  padding: 10px;
  border-radius: 5px;
`;

export default function Button() {
  return <button css={buttonStyle}>Emotion 버튼</button>;
}
```

- **JS 파일 내부에서 CSS를 작성**할 수 있습니다.
- 스타일이 **동적으로 변경**될 때 유용합니다.

---

## **7. 글로벌 스타일과 컴포넌트 스타일 결합하기**  

Next.js에서는 **글로벌 스타일과 컴포넌트 단위 스타일을 결합**해 사용할 수 있습니다. 예를 들어, 글로벌 CSS로 **기본 레이아웃**을 정의하고, 개별 컴포넌트에는 **CSS Modules**나 **Styled JSX**를 적용하는 방식입니다.

---

## **8. 스타일링 최적화 팁**  

- **컴포넌트 단위 스타일**을 사용해 스타일 충돌을 방지합니다.  
- **Tailwind CSS**와 같은 유틸리티 클래스 프레임워크를 사용해 빠르게 UI를 개발합니다.  
- **Sass**를 사용해 복잡한 스타일을 관리합니다.  
- **CSS Modules**를 활용해 재사용 가능한 컴포넌트를 만듭니다.  
- 성능 최적화를 위해 **필요한 CSS만 로드**하도록 합니다.

---

## **9. 정리**  

Next.js는 **다양한 스타일링 옵션**을 제공해 프로젝트의 요구에 맞게 유연하게 스타일을 적용할 수 있습니다.  
- **CSS Modules**: 스타일 충돌 방지 및 재사용성 향상  
- **Sass/SCSS**: 복잡한 스타일 관리  
- **Styled JSX**: 컴포넌트 내부에서 스타일 작성  
- **Tailwind CSS**: 빠른 스타일 작성 및 커스터마이징  

여러 스타일링 방법을 조합해 사용하면 **최적화된 UI 개발**과 **유연한 스타일 관리**가 가능합니다. 🎨🚀
