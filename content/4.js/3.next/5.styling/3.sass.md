## **1. Sass 설치**  

먼저 **Sass 패키지**를 프로젝트에 설치합니다.

```bash
npm install sass
```

- 이 명령어는 Sass를 설치하며, **`.scss` 또는 `.sass`** 파일을 사용할 수 있도록 해줍니다.

---

## **2. Sass 파일 생성 및 사용**  

Next.js에서는 **Sass 파일**을 컴포넌트와 페이지에서 직접 import할 수 있습니다.

### **예제 1: SCSS 파일 생성**  
`styles/globals.scss` 파일을 생성합니다.

```scss
/* styles/globals.scss */
$primary-color: #3498db;

body {
  margin: 0;
  padding: 0;
  font-family: Arial, sans-serif;
  background-color: $primary-color;
}
```

### **예제 2: SCSS 파일 사용하기**  
```javascript
// pages/_app.js
import '../styles/globals.scss';

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />;
}
```

- **`_app.js`** 파일에서 글로벌 스타일을 import하면 애플리케이션 전체에 적용됩니다.

---

## **3. 컴포넌트 단위 SCSS 사용**  

컴포넌트별로 스타일을 작성할 때 **CSS Modules와 SCSS**를 함께 사용하면 스타일을 컴포넌트에 국한시킬 수 있습니다.

### **예제: SCSS 모듈 사용하기**  
`styles/Button.module.scss` 파일을 생성합니다.

```scss
/* styles/Button.module.scss */
$button-color: #4caf50;

.button {
  background-color: $button-color;
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 5px;
  cursor: pointer;

  &:hover {
    background-color: darken($button-color, 10%);
  }
}
```

```javascript
// components/Button.js
import styles from '../styles/Button.module.scss';

export default function Button() {
  return <button className={styles.button}>클릭하세요!</button>;
}
```

- **SCSS 모듈**을 사용하면 스타일이 **컴포넌트 내부에만 적용**됩니다.
- 변수와 중첩 스타일 등을 활용해 **깔끔하고 재사용 가능한 스타일**을 작성할 수 있습니다.

## **4. SCSS의 유용한 기능들**  

### **1) 변수 사용하기**  
SCSS에서는 **변수**로 반복되는 값을 관리할 수 있습니다.
```scss
/* styles/variables.scss */
$primary-color: #3498db;
$secondary-color: #2ecc71;
```

```scss
/* styles/layout.scss */
@import 'variables';

.header {
  background-color: $primary-color;
  color: white;
}

.footer {
  background-color: $secondary-color;
}
```

### **2) 중첩 스타일링**  
SCSS에서는 **중첩**을 통해 계층 구조를 더 직관적으로 표현할 수 있습니다.
```scss
/* styles/Card.module.scss */
.card {
  border: 1px solid #ddd;
  padding: 20px;

  .title {
    font-size: 24px;
    font-weight: bold;
  }

  .content {
    margin-top: 10px;
    color: #666;
  }
}
```

## **5. 글로벌 스타일과 컴포넌트 스타일 결합하기**  

Next.js에서는 **글로벌 스타일과 컴포넌트 단위 SCSS**를 조합할 수 있습니다. 예를 들어, 글로벌 SCSS로 **기본 레이아웃**을 정의하고, 각 컴포넌트에 **SCSS 모듈**을 적용하는 방식입니다.

---

## **6. 반응형 디자인 적용**  

SCSS에서는 **미디어 쿼리**를 사용해 쉽게 반응형 디자인을 적용할 수 있습니다.

```scss
/* styles/Header.module.scss */
.header {
  padding: 20px;

  @media (max-width: 768px) {
    padding: 10px;
    font-size: 14px;
  }
}
```

---

## **7. 성능 최적화**  

### **사용하지 않는 CSS 제거**  
SCSS로 작성된 스타일이 많아지면 번들 크기가 커질 수 있습니다. 이를 방지하기 위해 **Purging** 설정을 사용합니다. Tailwind CSS와 같이 **PostCSS**를 사용해 최적화할 수도 있습니다.

---

## **8. Next.js와 Sass의 장점**  

- **모듈식 스타일 관리**: SCSS 모듈을 통해 컴포넌트 단위로 스타일을 관리할 수 있습니다.
- **유연한 스타일링**: 변수, 믹스인, 중첩 등을 사용해 더 강력한 스타일을 작성할 수 있습니다.
- **반응형 디자인**: 미디어 쿼리와 SCSS를 활용해 다양한 디바이스에 맞게 스타일을 조정할 수 있습니다.
- **CSS 충돌 방지**: CSS Modules를 사용해 스타일 충돌을 방지합니다.

---

## **9. 마무리**  

Next.js에서 Sass/SCSS를 사용하면 **더 구조적이고 효율적인 스타일 작성**이 가능합니다. **변수, 중첩 스타일, 모듈화** 등의 기능을 통해 유지보수가 쉬워지고, 반응형 디자인에도 유리합니다. **SCSS와 CSS Modules를 조합**해 컴포넌트 기반 개발을 극대화하고, 프로젝트의 규모와 복잡도에 따라 **유연하게 스타일을 관리**할 수 있습니다. 🎨🚀
