## **1. styled-jsx: Next.js 기본 내장 CSS-in-JS**  

Next.js에는 **`styled-jsx`**가 내장되어 있어 별도의 설치 없이 바로 사용할 수 있습니다. 컴포넌트 내에 CSS를 선언하면 해당 컴포넌트에만 **로컬 스코프**로 적용됩니다.

### **예제: styled-jsx 사용하기**  
```javascript
export default function Home() {
  return (
    <div>
      <h1>Next.js CSS-in-JS</h1>
      <p>이 문장은 스타일이 적용됩니다.</p>
      <style jsx>{`
        h1 {
          color: blue;
        }
        p {
          font-size: 18px;
          color: gray;
        }
      `}</style>
    </div>
  );
}
```
- **`<style jsx>`**: 스타일이 해당 컴포넌트 내에서만 적용됩니다.  
- **CSS 충돌을 방지**하고 각 컴포넌트가 고유한 스타일을 가집니다.

## **2. 전역 스타일 정의하기**  

컴포넌트 외부에서도 **전역 스타일**을 정의할 수 있습니다. 이를 위해 **`global`** 속성을 사용합니다.

### **예제: 전역 스타일 적용**  
```javascript
export default function MyApp({ Component, pageProps }) {
  return (
    <>
      <Component {...pageProps} />
      <style jsx global>{`
        body {
          margin: 0;
          padding: 0;
          font-family: Arial, sans-serif;
        }
      `}</style>
    </>
  );
}
```
- **`jsx global`**: 스타일이 애플리케이션 전체에 적용됩니다.

## **3. 조건부 스타일 적용하기**  

JavaScript 변수를 활용해 **동적으로 스타일을 변경**할 수 있습니다.

### **예제: 동적 스타일 적용**  
```javascript
export default function Button({ isPrimary }) {
  return (
    <button>
      버튼
      <style jsx>{`
        button {
          background-color: ${isPrimary ? 'blue' : 'gray'};
          color: white;
          padding: 10px 20px;
          border: none;
          border-radius: 5px;
        }
      `}</style>
    </button>
  );
}
```
- **`isPrimary`**에 따라 **파란색** 또는 **회색** 배경이 적용됩니다.

## **4. CSS-in-JS의 장점과 단점**  

### **장점**  
- **스타일 충돌 방지**: 각 컴포넌트가 고유한 스타일 스코프를 가집니다.  
- **동적 스타일**: JavaScript 로직을 활용해 조건부 스타일을 쉽게 적용할 수 있습니다.  
- **코드 간소화**: 스타일과 로직을 한 파일에서 관리해 컴포넌트 유지보수가 쉬워집니다.

### **단점**  
- **복잡한 스타일 작성 어려움**: CSS-in-JS는 복잡한 CSS 규칙 작성에 불리할 수 있습니다.  
- **런타임 성능 문제**: 스타일이 컴포넌트 렌더링 시 생성되므로 성능에 영향을 줄 수 있습니다.

## **5. 외부 CSS-in-JS 라이브러리 사용하기**  

Next.js는 **Emotion, Styled Components** 같은 외부 CSS-in-JS 라이브러리와도 호환됩니다. 이들 라이브러리는 더 강력한 기능과 유연한 스타일링을 제공합니다.

### **Emotion 설치 및 사용 예제**  
```bash
npm install @emotion/react @emotion/styled
```

```javascript
/** @jsxImportSource @emotion/react */
import { css } from '@emotion/react';

const style = css`
  color: hotpink;
`;

export default function Home() {
  return <div css={style}>Hello, Emotion!</div>;
}
```

## **6. CSS-in-JS와 SSR(서버 사이드 렌더링)**  

Next.js는 **SSR(서버 사이드 렌더링)**을 지원하므로 **CSS-in-JS 스타일**도 서버에서 미리 렌더링됩니다. 이로 인해 **페이지 로딩 속도**가 빨라지고 **SEO 성능**이 향상됩니다.

---

## **7. CSS-in-JS와 성능 최적화**  

CSS-in-JS는 스타일이 컴포넌트 렌더링 시 적용되므로 성능에 영향을 미칠 수 있습니다. 이를 최소화하기 위해:
- **컴포넌트 단위로 스타일을 최소화**합니다.
- **반복적인 스타일은 전역으로 분리**합니다.
- **캐싱 전략**을 사용해 불필요한 렌더링을 방지합니다.

---

## **8. CSS-in-JS의 사용 예시 정리**  

- **로컬 스코프 스타일**: 컴포넌트 내부에서만 스타일을 제한합니다.
- **동적 스타일**: JavaScript 변수를 활용해 조건부 스타일을 적용합니다.
- **전역 스타일**: 애플리케이션 전체에 공통 스타일을 정의합니다.
- **외부 CSS-in-JS 라이브러리 활용**: Emotion, Styled Components 등을 사용해 더 강력한 기능을 제공합니다.
