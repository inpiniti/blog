## **1. `next/image` 소개**  

**`next/image`** 컴포넌트는 기본적인 `<img>` 태그보다 더 나은 기능을 제공합니다.  
- **지연 로딩**(Lazy loading)  
- **자동 포맷 변환** (예: WebP)  
- **브라우저 크기별 리사이징**  
- **Responsive 디자인** 지원  
- **캐싱 및 성능 최적화**  

---

## **2. `next/image` 설치 및 기본 사용법**  

Next.js 프로젝트에는 기본적으로 `next/image`가 포함되어 있으므로 별도 설치가 필요하지 않습니다.

### **예제: 기본 사용법**  
```javascript
import Image from 'next/image';

export default function Home() {
  return (
    <div>
      <h1>Next.js 이미지 최적화</h1>
      <Image 
        src="/images/sample.jpg" 
        alt="샘플 이미지" 
        width={600} 
        height={400} 
      />
    </div>
  );
}
```

- **`src`**: 로컬 이미지 파일 또는 외부 URL을 사용할 수 있습니다.
- **`width`, `height`**: 이미지를 해당 크기로 렌더링합니다.  
- 이 컴포넌트를 사용하면 Next.js가 자동으로 **지연 로딩**과 **최적화된 형식**으로 변환합니다.

---

## **3. 레이아웃 조정 옵션**  

`next/image`는 다양한 **레이아웃** 옵션을 지원해 이미지가 화면에 맞게 조절되도록 합니다.

### **`layout="intrinsic"`**  
- 이미지의 **원래 비율**을 유지하며 크기를 조정합니다.
```javascript
<Image 
  src="/images/sample.jpg" 
  alt="샘플 이미지" 
  layout="intrinsic" 
  width={600} 
  height={400} 
/>
```

### **`layout="responsive"`**  
- 이미지가 **부모 요소의 너비**에 맞게 반응형으로 조절됩니다.
```javascript
<Image 
  src="/images/sample.jpg" 
  alt="샘플 이미지" 
  layout="responsive" 
  width={600} 
  height={400} 
/>
```

### **`layout="fill"`**  
- 이미지가 부모 요소를 **완전히 채우도록** 조정됩니다.
```javascript
<div style={{ position: 'relative', width: '100%', height: '300px' }}>
  <Image 
    src="/images/sample.jpg" 
    alt="샘플 이미지" 
    layout="fill" 
    objectFit="cover" 
  />
</div>
```

- **`objectFit`** 속성은 이미지가 부모 요소를 채우는 방식을 조정합니다. (`cover`, `contain`, `fill` 등)

## **4. 외부 이미지 사용하기**  

외부 URL에서 이미지를 사용할 때는 **`next.config.js`** 파일에 **도메인 허용** 설정을 해야 합니다.

### **예제: 외부 이미지 설정**  
```javascript
// next.config.js
module.exports = {
  images: {
    domains: ['example.com'],
  },
};
```

```javascript
<Image 
  src="https://example.com/sample.jpg" 
  alt="외부 이미지" 
  width={600} 
  height={400} 
/>
```

- **`domains`** 배열에 외부 이미지를 제공하는 도메인을 추가합니다.

---

## **5. 품질 및 최적화 설정**  

`next/image`는 이미지 품질을 조정할 수 있습니다. 기본 품질은 75이며, **1~100 사이의 값**을 사용합니다.

```javascript
<Image 
  src="/images/sample.jpg" 
  alt="샘플 이미지" 
  width={600} 
  height={400} 
  quality={80} 
/>
```

---

## **6. 지연 로딩 (Lazy Loading)**  

모든 이미지는 **기본적으로 지연 로딩**됩니다. 필요에 따라 지연 로딩을 비활성화할 수 있습니다.

```javascript
<Image 
  src="/images/sample.jpg" 
  alt="샘플 이미지" 
  width={600} 
  height={400} 
  loading="eager" 
/>
```

- **`eager`**: 페이지 로딩 시 즉시 이미지를 로딩합니다.  
- **`lazy`**: (기본값) 화면에 나타날 때 이미지를 로딩합니다.

---

## **7. 블러 처리 및 Placeholder 사용**  

이미지 로딩 전까지 **블러(Blur) 효과**나 다른 Placeholder를 표시할 수 있습니다.

### **예제: 블러 처리 사용**  
```javascript
<Image 
  src="/images/sample.jpg" 
  alt="샘플 이미지" 
  width={600} 
  height={400} 
  placeholder="blur" 
  blurDataURL="/images/blur-sample.jpg" 
/>
```

- **`placeholder="blur"`**: 이미지가 로딩될 때 블러 효과를 표시합니다.
- **`blurDataURL`**: 로딩 전 표시할 저해상도 이미지의 URL입니다.

---

## **8. 성능 최적화를 위한 이미지 캐싱**  

Next.js는 이미지를 자동으로 **캐싱**해 성능을 최적화합니다. 이미지는 60초 동안 캐시되며, 필요에 따라 재검증됩니다.

### **캐시 만료 시간 설정**  
```javascript
// next.config.js
module.exports = {
  images: {
    minimumCacheTTL: 60,  // 단위: 초
  },
};
```

---

## **9. 유의할 점**  

1. **정적 이미지**: `public` 폴더에 저장된 이미지는 **`/images/...` 경로**로 직접 접근할 수 있습니다.
2. **외부 이미지 최적화**: 외부 이미지는 서버에서 직접 최적화됩니다. 도메인 설정을 올바르게 해야 합니다.
3. **SEO 고려**: 모든 이미지에 **`alt`** 속성을 설정해 접근성과 SEO를 높입니다.

## **10. 마무리**  

Next.js의 **`next/image` 컴포넌트**를 사용하면 **이미지 최적화와 성능 향상**을 손쉽게 구현할 수 있습니다. **지연 로딩, 반응형 이미지, 외부 이미지 지원, 블러 처리** 등의 기능은 **사용자 경험을 개선**하며, Next.js의 **자동 캐싱**과 **포맷 변환**은 애플리케이션 성능을 최적화합니다.
