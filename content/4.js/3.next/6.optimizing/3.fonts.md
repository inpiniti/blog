## **1. `next/font` 사용하기**  

Next.js 13 이상에서는 **`next/font`** 패키지를 통해 **Google Fonts 및 사용자 정의 폰트**를 쉽게 최적화할 수 있습니다. 폰트가 **서버 측에서 렌더링**되어 FOUT(Flash Of Unstyled Text) 현상을 방지하고 성능을 향상시킵니다.  

### **설치 및 기본 사용법**  
**Google Fonts**를 최적화하여 사용하는 방법입니다.

```javascript
// 폰트 가져오기 (예: Roboto)
import { Roboto } from 'next/font/google';

const roboto = Roboto({
  subsets: ['latin'],
  weight: ['400', '700'], // 사용할 폰트 두께 지정
  display: 'swap',         // 로딩 중 기본 폰트로 대체
});

export default function Home() {
  return (
    <div className={roboto.className}>
      <h1>최적화된 폰트 사용 예제</h1>
      <p>이 페이지는 Roboto 폰트를 사용합니다.</p>
    </div>
  );
}
```

- **`subsets`**: 폰트의 언어 세트를 지정합니다.  
- **`weight`**: 사용할 폰트의 두께를 설정합니다.  
- **`display: 'swap'`**: 폰트가 로드되기 전에 시스템 폰트가 표시되도록 합니다.

## **2. 사용자 정의 폰트 사용하기**  

로컬 또는 외부 경로의 **사용자 정의 폰트**도 `next/font/local`로 최적화할 수 있습니다.

```javascript
// 로컬 폰트 가져오기
import localFont from 'next/font/local';

const customFont = localFont({
  src: [
    {
      path: '/fonts/CustomFont-Regular.woff2',
      weight: '400',
    },
    {
      path: '/fonts/CustomFont-Bold.woff2',
      weight: '700',
    },
  ],
  display: 'swap',
});

export default function Home() {
  return (
    <div className={customFont.className}>
      <h1>사용자 정의 폰트 예제</h1>
      <p>이 텍스트는 CustomFont를 사용합니다.</p>
    </div>
  );
}
```

- **`src`**: 폰트 파일 경로와 폰트 두께를 지정합니다.  
- **`display: 'swap'`**: 로딩 중 기본 폰트를 표시하여 사용자 경험을 개선합니다.

---

## **3. 폰트 최적화 옵션**  

### **`display` 속성**  
- **`auto`**: 브라우저의 기본 폰트 로딩 전략을 따릅니다.  
- **`block`**: 폰트가 로드될 때까지 텍스트가 표시되지 않습니다.  
- **`swap`**: 폰트가 로드되기 전까지 기본 시스템 폰트를 사용합니다. **(권장)**  
- **`fallback`**: 일정 시간 동안 시스템 폰트를 사용하고, 이후 폰트가 로드되면 교체합니다.

### **`preload` 설정**  
폰트를 **미리 로드**해 성능을 개선할 수 있습니다.

```javascript
const roboto = Roboto({
  subsets: ['latin'],
  preload: true, // 페이지 로딩 전에 미리 로드
});
```

## **4. 성능과 SEO를 고려한 폰트 사용**  

1. **필요한 두께와 언어만 가져오기**: 불필요한 폰트 데이터를 최소화합니다.  
2. **캐싱 활용**: 폰트가 여러 페이지에서 사용될 경우 브라우저 캐시를 활용합니다.  
3. **서버 측 렌더링(SSR)**: 폰트를 서버에서 렌더링하면 CLS(Cumulative Layout Shift)를 방지합니다.  

---

## **5. FOUT와 FOIT 방지하기**  

- **FOUT**(Flash Of Unstyled Text): 폰트가 로드되기 전에 텍스트가 기본 폰트로 표시되는 현상입니다.  
- **FOIT**(Flash Of Invisible Text): 폰트가 로드될 때까지 텍스트가 보이지 않는 현상입니다.  

**`display: 'swap'`** 옵션을 사용하면 **FOUT**를 방지하면서 성능을 유지할 수 있습니다.

---

## **6. 최적화된 Google Fonts 사용하기**  

Next.js에서는 Google Fonts를 최적화할 때 폰트 파일이 **CDN**을 거치지 않고 **직접 서버에서 제공**됩니다. 이를 통해 더 빠르고 안정적인 성능을 제공합니다.

---

## **7. 마무리**  

Next.js의 **폰트 최적화** 기능을 사용하면 페이지 로딩 속도를 개선하고, FOUT/FOIT와 같은 문제를 해결할 수 있습니다. **Google Fonts와 사용자 정의 폰트를 쉽게 적용**하고 **지연 로딩 및 미리 로딩** 전략을 통해 성능과 사용자 경험을 극대화하세요. 🚀
