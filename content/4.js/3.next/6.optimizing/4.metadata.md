## **1. 메타데이터 설정의 기본 개념**  

메타데이터는 **페이지의 제목, 설명, 키워드, Open Graph, 트위터 카드 등**을 정의하는 정보를 포함합니다. Next.js에서는 `app/` 디렉터리의 각 **페이지와 레이아웃 파일**에서 메타데이터를 설정할 수 있습니다.  

---

## **2. 메타데이터 설정 방법**  

### **기본 메타데이터 설정**  
페이지나 레이아웃에 메타데이터를 추가할 때는 **`metadata`** 객체를 사용합니다. 

```javascript
export const metadata = {
  title: '내 멋진 웹사이트',
  description: '이 웹사이트는 최신 정보를 제공합니다.',
};

export default function HomePage() {
  return <h1>홈페이지입니다</h1>;
}
```

- **`title`**: 페이지의 제목을 설정합니다.  
- **`description`**: 페이지에 대한 설명을 제공합니다.

---

## **3. SEO 메타데이터 설정**  

SEO에 필요한 메타 태그를 **자동 생성**할 수 있습니다.

```javascript
export const metadata = {
  title: 'Next.js 최적화된 사이트',
  description: 'Next.js로 구축한 빠르고 최적화된 웹사이트입니다.',
  keywords: ['Next.js', 'SEO', '웹사이트 최적화'],
  author: '홍길동',
};
```

- **`keywords`**: 페이지와 관련된 키워드를 설정합니다.  
- **`author`**: 페이지 작성자 정보를 추가합니다.

---

## **4. Open Graph와 소셜 미디어 메타데이터 설정**  

Open Graph 메타데이터는 **Facebook과 같은 소셜 플랫폼**에서 콘텐츠를 공유할 때 유용합니다.

```javascript
export const metadata = {
  title: 'Next.js 웹사이트',
  description: 'Next.js로 만든 멋진 웹사이트입니다.',
  openGraph: {
    title: 'Next.js 웹사이트',
    description: 'Next.js로 만든 멋진 웹사이트입니다.',
    url: 'https://example.com',
    images: [
      {
        url: 'https://example.com/og-image.jpg',
        width: 800,
        height: 600,
        alt: '웹사이트 미리보기 이미지',
      },
    ],
  },
  twitter: {
    card: 'summary_large_image',
    site: '@example',
    title: 'Next.js 웹사이트',
    description: 'Next.js로 만든 멋진 웹사이트입니다.',
    image: 'https://example.com/twitter-image.jpg',
  },
};
```

- **`openGraph`**: Open Graph 태그를 정의하여 미리보기를 설정합니다.  
- **`twitter`**: 트위터 카드 정보를 설정해 공유 시 표시될 내용을 지정합니다.

## **5. 동적 메타데이터 설정하기**  

Next.js에서는 **비동기 메타데이터 설정**이 가능합니다. API에서 데이터를 가져와 메타데이터를 동적으로 생성할 수 있습니다.

```javascript
export async function generateMetadata({ params }) {
  const product = await fetch(`https://api.example.com/products/${params.id}`).then((res) => res.json());

  return {
    title: product.name,
    description: product.description,
  };
}

export default function ProductPage({ params }) {
  return <h1>{params.id} 제품 페이지</h1>;
}
```

- **`generateMetadata`**: 비동기 함수로 메타데이터를 생성합니다.

## **6. 글로벌 메타데이터 설정**  

`layout.js` 파일에서 **전역 메타데이터**를 정의하여 모든 페이지에 공통으로 적용할 수 있습니다.

```javascript
export const metadata = {
  title: 'Next.js 사이트',
  description: '모든 페이지에 적용되는 기본 메타데이터입니다.',
};
```

---

## **7. 메타데이터 캐싱 및 성능 최적화**  

- **정적 페이지 생성(SSG)**: 메타데이터를 미리 생성하여 빠르게 제공할 수 있습니다.  
- **CDN 캐시 활용**: 메타데이터가 자주 변경되지 않는 경우, **캐싱**을 통해 성능을 최적화할 수 있습니다.  

---

## **8. 로봇 메타 태그 설정**  

검색 엔진의 인덱싱을 제어하기 위해 **로봇 메타 태그**를 설정할 수 있습니다.

```javascript
export const metadata = {
  robots: {
    index: true,
    follow: true,
    nocache: true,
  },
};
```

- **`index`**: 검색 엔진이 페이지를 인덱싱할지 결정합니다.  
- **`follow`**: 페이지의 링크를 따라갈지 설정합니다.  
- **`nocache`**: 페이지를 캐시하지 않도록 지정합니다.

---

## **9. 메타데이터와 접근성**  

- 메타데이터는 검색 엔진뿐만 아니라 **스크린 리더**와 같은 접근성 도구에도 유용합니다.  
- **적절한 제목과 설명**을 제공하면 사용자가 콘텐츠를 쉽게 이해할 수 있습니다.
