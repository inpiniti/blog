---

## **1. `next/script` 컴포넌트 사용하기**  

Next.js는 **`next/script`** 컴포넌트를 제공해 **스크립트 로딩 방식**을 쉽게 제어할 수 있습니다.

### **기본 사용법**  
아래는 외부 스크립트를 추가하는 예제입니다.

```javascript
import Script from 'next/script';

export default function HomePage() {
  return (
    <>
      <h1>홈페이지</h1>
      <Script 
        src="https://example.com/library.js" 
        strategy="beforeInteractive"
      />
    </>
  );
}
```

---

## **2. `strategy` 옵션으로 로딩 방식 제어하기**  

`strategy` 속성은 스크립트 로딩 방식을 정의하며, **페이지 로딩과의 상호작용**을 최적화할 수 있습니다.

- **`beforeInteractive`**: 페이지가 **렌더링되기 전에** 스크립트를 로딩합니다.  
- **`afterInteractive`**: 페이지가 **렌더링된 후** 스크립트를 로딩합니다. (기본값)  
- **`lazyOnload`**: 페이지와 상관없이 **사용자가 필요할 때** 스크립트를 로드합니다.

```javascript
<Script 
  src="https://example.com/library.js" 
  strategy="lazyOnload" 
/>
```

이 설정은 **성능 최적화**를 위해 사용됩니다. 예를 들어, 중요하지 않은 분석 도구나 광고 스크립트는 `lazyOnload`로 설정해 페이지 로딩을 방해하지 않도록 합니다.

---

## **3. 스크립트의 순서 제어하기**  

여러 개의 스크립트가 있을 때, **종속 관계**에 따라 로딩 순서를 지정할 수 있습니다. 

```javascript
<Script 
  src="https://example.com/dependency.js" 
  strategy="beforeInteractive" 
/>
<Script 
  src="https://example.com/main.js" 
  strategy="afterInteractive" 
/>
```

여기서는 `dependency.js`가 먼저 로드되고, 페이지가 렌더된 후에 `main.js`가 로드됩니다.

---

## **4. HTML 스크립트 직접 삽입하기**  

특정 기능을 위해 **인라인 스크립트**를 삽입할 수 있습니다.

```javascript
<Script id="inline-script" strategy="afterInteractive">
  {`
    console.log('인라인 스크립트가 실행됩니다.');
  `}
</Script>
```

- **`id` 속성**: 스크립트를 고유하게 식별할 수 있도록 합니다.  
- 스크립트 내부에 **JSX 템플릿 리터럴**을 사용합니다.

---

## **5. 외부 스크립트와 CSP(Content Security Policy)**  

외부 스크립트를 사용할 때 **Content Security Policy(CSP)**를 설정해 보안을 강화할 수 있습니다. CSP는 외부 스크립트 로딩을 허용하거나 제한하는 정책입니다.

```html
<meta http-equiv="Content-Security-Policy" content="script-src 'self' https://example.com">
```

이렇게 설정하면 **`self`(자체 서버)와 `https://example.com`**에서만 스크립트를 로딩할 수 있습니다.

---

## **6. 비동기 및 지연 로딩 최적화**  

Next.js의 **비동기 로딩** 기능을 활용하면 페이지 로딩 중단 없이 스크립트를 로딩할 수 있습니다.

- **async**: 스크립트가 **비동기적으로 로딩**됩니다.
- **defer**: 페이지가 완전히 로딩된 후 스크립트가 실행됩니다.

```javascript
<Script 
  src="https://example.com/async-library.js" 
  strategy="afterInteractive" 
  async 
/>
```

---

## **7. 스크립트 최적화가 중요한 이유**  

1. **렌더링 지연 방지**: 필수 스크립트만 먼저 로딩해 빠른 렌더링을 유지합니다.  
2. **SEO 개선**: 검색 엔진이 스크립트로 인해 인덱싱을 지연하지 않도록 합니다.  
3. **사용자 경험 향상**: 불필요한 스크립트 로딩으로 인한 페이지 지연을 줄입니다.  

---

## **8. 스크립트의 메모리 관리**  

SPA(Single Page Application)에서는 **페이지 전환 시 스크립트가 중복 실행되는 문제**가 발생할 수 있습니다. 이를 방지하려면 **상태 관리**와 **적절한 로드 전략**을 설정하는 것이 중요합니다.

---

## **9. 마무리**  

Next.js의 **스크립트 최적화** 기능은 성능과 사용자 경험을 향상시키는 데 필수적입니다. `next/script` 컴포넌트를 활용하면 **비동기 로딩, 지연 로딩, 순서 제어** 등 다양한 방법으로 스크립트를 효율적으로 관리할 수 있습니다. 필요한 경우에만 스크립트를 로딩하고, 보안을 위해 CSP를 적용해 최적화된 웹 애플리케이션을 만들어 보세요! 🚀
