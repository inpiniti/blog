---
title: 지연 로딩(Lazy Loading) 최적화
description: Lazy Loading(지연 로딩)은 초기 페이지 로딩 시 모든 콘텐츠를 한 번에 로딩하지 않고, 필요한 시점에만 리소스를 불러오는 방식입니다. 이 기법은 성능을 최적화하고 초기 로딩 속도를 개선하며, 특히 이미지, 비디오, 컴포넌트와 같은 무거운 리소스에 효과적입니다.
---

## **1. Lazy Loading의 장점**  
- **초기 로딩 시간 단축**: 중요한 콘텐츠만 먼저 로드해 사용자가 빠르게 페이지에 접근할 수 있습니다.
- **네트워크 최적화**: 필요한 리소스만 요청해 **불필요한 데이터 소비**를 줄입니다.
- **사용자 경험 개선**: 사용자가 필요할 때만 리소스를 로딩하므로 빠른 반응성을 제공합니다.

---

## **2. 이미지 지연 로딩**  

Next.js의 `<Image />` 컴포넌트는 기본적으로 **지연 로딩**을 지원합니다.

```javascript
import Image from 'next/image';

export default function Home() {
  return (
    <Image 
      src="/example.jpg" 
      alt="예제 이미지" 
      width={500} 
      height={500} 
      loading="lazy" 
    />
  );
}
```

- **`loading="lazy"`**: 해당 이미지가 **뷰포트에 진입할 때** 로드됩니다.
- Next.js는 **이미지 최적화**를 자동으로 수행하여 성능을 극대화합니다.

---

## **3. 동적 컴포넌트 로딩**  

Next.js의 **동적 import**를 활용하면, 특정 컴포넌트를 필요한 시점에만 로딩할 수 있습니다.

```javascript
import dynamic from 'next/dynamic';

const HeavyComponent = dynamic(() => import('../components/HeavyComponent'), {
  loading: () => <p>로딩 중...</p>, 
  ssr: false,
});

export default function HomePage() {
  return <HeavyComponent />;
}
```

- **`dynamic`**: 컴포넌트를 **지연 로딩**합니다.
- **`ssr: false`**: 서버 측 렌더링을 비활성화하고 클라이언트 측에서만 로딩합니다.
- **`loading`** 속성으로 **로딩 중 표시**를 정의할 수 있습니다.

---

## **4. 비디오 지연 로딩**  

비디오는 많은 네트워크 리소스를 소모하므로 지연 로딩하는 것이 좋습니다.

```html
<video controls preload="none">
  <source src="/example.mp4" type="video/mp4" />
  브라우저가 비디오를 지원하지 않습니다.
</video>
```

- **`preload="none"`**: 비디오가 재생되기 전까지는 로드되지 않습니다.
- 사용자가 **필요할 때만** 비디오가 로딩되므로 성능이 개선됩니다.

---

## **5. 스크립트 지연 로딩**  

Next.js에서는 **`next/script`**를 통해 스크립트를 지연 로드할 수 있습니다.

```javascript
import Script from 'next/script';

export default function HomePage() {
  return (
    <>
      <h1>홈페이지</h1>
      <Script 
        src="https://example.com/library.js" 
        strategy="lazyOnload" 
      />
    </>
  );
}
```

- **`strategy="lazyOnload"`**: 페이지 로드가 완료된 후에 스크립트가 로딩됩니다.
- 불필요한 스크립트 로딩을 늦춰 **초기 렌더링 속도를 개선**합니다.

---

## **6. Intersection Observer를 활용한 지연 로딩**  

브라우저의 **Intersection Observer API**를 활용해 직접 지연 로딩 로직을 구현할 수 있습니다.

```javascript
import { useEffect, useState } from 'react';

function LazyComponent() {
  const [isVisible, setIsVisible] = useState(false);

  useEffect(() => {
    const observer = new IntersectionObserver(([entry]) => {
      if (entry.isIntersecting) {
        setIsVisible(true);
        observer.disconnect();
      }
    });

    observer.observe(document.getElementById('lazy-element'));

    return () => observer.disconnect();
  }, []);

  return (
    <div id="lazy-element">
      {isVisible ? <p>콘텐츠가 로드되었습니다!</p> : <p>로딩 중...</p>}
    </div>
  );
}

export default LazyComponent;
```

- **Intersection Observer**를 사용하면 특정 요소가 뷰포트에 진입할 때만 콘텐츠를 로딩합니다.

---

## **7. 지연 로딩이 중요한 이유**  

1. **모바일 환경 최적화**: 네트워크가 느린 모바일 환경에서 지연 로딩이 큰 차이를 만듭니다.
2. **SEO 개선**: Next.js는 필요한 콘텐츠만 로드해 검색 엔진이 페이지를 빠르게 크롤링할 수 있게 합니다.
3. **UX 개선**: 사용자는 필요한 콘텐츠만 로딩되므로 빠른 반응성을 경험합니다.

---

## **8. 마무리**  

Next.js의 **지연 로딩(Lazy Loading)** 기능을 활용하면 성능과 사용자 경험을 모두 향상시킬 수 있습니다. 이미지, 컴포넌트, 비디오, 스크립트 등을 **필요한 시점에만 로드**하도록 설정해 네트워크 리소스를 절약하고, 초기 로딩 시간을 최소화하세요. 이러한 최적화는 **웹사이트의 성능을 크게 향상**시킬 수 있습니다. 🚀
